# 03 · 调味学基础

> 调味是烹饪的"灵魂"。理解味,才能调好味。

---

## 一、味觉的生理基础

**舌头上的味蕾**能识别 5 种基本味道:

| 味 | 感受 | 典型食物 |
|---|---|---|
| **甜** | 愉悦感 | 糖、蜂蜜、果糖 |
| **咸** | 增强其他味道 | 盐、酱油、咸菜 |
| **酸** | 提鲜、解腻 | 醋、柠檬、酸奶 |
| **苦** | 警示味(也可成为风味) | 咖啡、苦瓜 |
| **鲜** | 满足感(第七味) | 鸡精、海带、火腿 |

**辣不是味觉,是痛觉**——辣椒素激活口腔 TRPV1 受体。

### 味觉相互作用(关键!)

| 现象 | 例子 |
|---|---|
| **相乘作用**(1+1>2) | 鲜味+鲜味(鸡+菇)=N倍鲜 |
| **对比作用** | 酸味+糖=糖醋(酸让甜更清,甜让酸不刺) |
| **掩盖作用** | 糖掩盖辣;盐掩盖酸 |
| **协同作用** | 盐+糖+醋 → 多层次 |
| **消杀作用** | 大量盐抑制甜 |

---

## 二、咸味的"基础地位"

**盐是一切调味的地基**。

- 没盐,什么味都出不来
- 没盐,糖醋都是怪的(糖醋不"亮")
- 没盐,鲜味也提不出来(味精+盐才鲜)

### 盐的用量原则

**"成菜含盐量 0.8-1.5%"** 为宜(健康范围)

### 粗算公式

- **100g 食材 + 1g 盐**(约 1/4 茶匙)= 基础咸度
- **复杂菜**(2-3 人份,500-800g 食材)= **3-5g 盐**(约 1 茶匙)
- **汤**(1000ml 水)= **2-3g 盐**(约 1/2 茶匙)

### 用盐时机

| 时机 | 适合 | 不适合 |
|---|---|---|
| **腌制前** | 腌肉(嫩肉+底味) | — |
| **下锅前** | 炒青菜 | — |
| **中途** | 红烧、炖(分次加) | — |
| **出锅前** | 炒菜、凉拌 | — |
| **过晚** | × | 蔬菜出水/汤咸 |

---

## 三、甜味的"提鲜"作用

糖在烹饪中**不只提供甜**,还有:

1. **调味**:糖醋菜
2. **提鲜**:不加糖的红烧菜不饱满
3. **增亮**:糖让菜色更亮
4. **平衡**:中和咸、酸、辣
5. **挂色**:糖色
6. **嫩肉**:糖促进保水(但量少)

### 用糖量

- **家常菜**:3-5g(约 1 茶匙)
- **糖醋菜**:30-50g/500g 主料
- **糖色**:油+糖 1:1(糖 50g)
- **甜品**:10-30%

---

## 四、酸味的"魔法"

**酸味的厨房作用**:

1. **解腻**(肥肉+醋)
2. **提鲜**(酸让鲜味更鲜)
3. **保脆**(抑制果胶酶)
4. **去腥**(煮鱼加醋)
5. **嫩肉**(醋解肌纤维)
6. **平衡**(糖醋、番茄)
7. **防腐**(泡菜)

### 用醋量

- **解腻点蘸**:小碟装 5-10ml
- **凉拌**:5-15ml
- **糖醋菜**:30-50ml(糖:醋 1:1 起步)
- **煮鱼**:几滴就够

---

## 五、鲜味的"灵魂"

**鲜味的核心:核苷酸 + 谷氨酸**

### 鲜味来源(从高到低)

| 来源 | 鲜味成分 |
|---|---|
| 干贝、火腿、鸡汤 | 天然核苷酸 |
| 酱油、蚝油、鱼露 | 发酵产物 |
| 番茄、海带、香菇 | 谷氨酸 |
| 鸡精、味精 | 谷氨酸单钠(MSG) |
| 干蘑菇、火腿 | 鸟苷酸、肌苷酸 |

### 鲜味叠加公式

**MSG + 核苷酸 + 盐 = 强鲜味**(味精不是毒,适量无害)

### 配对技巧

- **番茄 + 蛋** → 番茄谷氨酸 + 蛋的氨基酸 → 鲜
- **鸡 + 菇** → 鸡的核苷酸 + 菇的谷氨酸 → 强鲜
- **鸡精 + 盐** → 鲜上加鲜(但都含盐,别过量)

---

## 六、辣味的"层次"

| 辣度 | 来源 | 典型菜 |
|---|---|---|
| **微辣** | 青椒 | 木须肉、青椒肉丝 |
| **中辣** | 干辣椒 | 辣子鸡、麻婆豆腐 |
| **重辣** | 二荆条、朝天椒 | 川菜主流 |
| **麻辣** | 花椒 + 辣椒 | 经典川渝菜 |
| **香辣** | 干辣椒 + 五香 | 湘菜主流 |
| **糊辣** | 辣椒炸到糊 | 宫保鸡丁 |

### 辣味的分子

- **辣椒素**:油溶,水溶差
- **花椒素**:麻(震颤感)
- **姜黄素**:暖

**辣味的激发**:
- 辣椒入油 → 辣味释放到油里(油辣子)
- 辣椒入热水 → 释放慢,汤辣

## 七、五味的组合 — 经典味型

### 1. 复合味型

| 味型 | 主料 | 比例(参考) | 代表菜 |
|---|---|---|---|
| **糖醋** | 糖 + 醋 | 糖:醋=1:1 或 2:1 | 糖醋排骨、鱼 |
| **咸鲜** | 盐 + 鲜味剂 | 盐主,味精辅 | 家常炒菜、汤 |
| **酸辣** | 醋 + 辣椒 | 酸辣平衡 | 酸辣土豆丝、酸辣汤 |
| **麻辣** | 花椒 + 辣椒 | 4:6 | 水煮鱼、麻婆豆腐 |
| **鱼香** | 糖醋 + 泡椒 + 葱姜蒜 + 酱油 | 糖:醋:酱油=1:1:2 | 鱼香肉丝 |
| **红烧** | 酱油 + 糖 + 八角 | 糖 10-30g,酱油 30ml | 红烧肉 |
| **宫保** | 干辣椒 + 花椒 + 糖醋 | 糖醋 1:1 | 宫保鸡丁 |
| **蚝油** | 蚝油 + 糖 + 酱油 | 蚝油主 | 蚝油生菜、牛肉 |
| **黑椒** | 黑胡椒 + 黄油 + 酱油 | 浓黑椒酱 | 黑椒牛柳 |

### 2. 单一味型

| 味型 | 调料 | 适合 |
|---|---|---|
| **蒜香** | 蒜 | 烤生蚝、蒜蓉虾 |
| **葱香** | 葱 | 葱油拌面 |
| **姜香** | 姜 | 姜撞奶、姜汁鸡 |
| **酱香** | 甜面酱 | 京酱肉丝 |
| **椒盐** | 花椒盐 | 椒盐排骨 |
| **麻辣** | 麻辣粉 | 冒菜 |

## 八、四季与味道偏好

- **夏**:清淡、酸味、凉拌(开胃)
- **冬**:浓厚、辣味、炖煮(暖身)
- **春**:鲜嫩、葱姜、芽菜(养肝)
- **秋**:润燥、咸鲜、梨藕(防燥)

## 九、调味的三阶段

每道菜的调味分**三次**:

```
第一阶段(腌制):给底味
  → 盐 + 料酒 + 姜片 + 葱段
  → 肉:10-30 分钟
  → 蔬菜:不腌或腌 5 分钟

第二阶段(加热中):给主味
  → 加酱油、蚝油、糖、盐
  → 一次主味决定
  → 注意:分次加比一次加灵活

第三阶段(出锅前):补味
  → 醋(遇高温挥发 → 出锅前加)
  → 葱花、香菜(留香)
  → 鸡精(过高温鲜味会丢)
  → 香油(关火后加)
```

## 十、调味失败的常见原因

| 现象 | 原因 |
|---|---|
| **菜太咸** | 盐一次性下多了、酱油也含盐没减量 |
| **菜太淡** | 忘记加盐、汤水太多稀释 |
| **菜没鲜味** | 没加鲜味调料(酱油/蚝油)或加盐太少 |
| **糖醋失衡** | 比例错位、醋用错(白醋太冲) |
| **腥味重** | 没焯水、没加料酒、没放姜 |
| **菜味寡淡** | 缺复合味,只用了单一调料 |
| **味道层次单薄** | 没分次调味、缺"回口"(回味) |

## 十一、调味的"五维平衡"

**专业厨师的心法**:

```
咸 ←————— → 甜
↑              ↓
酸 ←—— 中 ——→ 辣
↓              ↑
鲜              香
```

**好的菜 = 至少 3-4 维协调**

- **鱼香肉丝**:咸(酱油)+ 甜(糖)+ 酸(醋)+ 辣(泡椒)+ 鲜(肉)+ 香(葱姜蒜)
- **红烧肉**:咸(老抽)+ 甜(冰糖)+ 鲜(肉)+ 香(八角桂皮)
- **番茄炒蛋**:咸(盐)+ 甜(番茄+糖)+ 鲜(蛋)+ 香(葱)

## 十二、试味的科学

**每一阶段都要试味**!

### 试味工具

- **筷子**:最常用,蘸汤汁尝
- **小勺**:汤类
- **手指**(经验法):用于腌肉时尝盐度

### 试味三要点

1. **热尝咸,凉尝甜,温尝鲜**(温度影响味觉感受)
2. **不要空腹试味**(味觉疲劳)
3. **菜做得差不多了再大量调味**(避免半途加满)

## 十四、调味的"黄金原则"

1. **盐是基础** — 没盐什么味都空
2. **糖是缓冲** — 糖醋平衡、糖提鲜
3. **酱油分次** — 生抽调味、老抽上色
4. **醋要后放** — 高温下醋挥发,出锅前加
5. **酒去腥** — 加热前加,留时间挥发
6. **葱姜蒜爆香** — 大多数炒菜的开端
7. **试味决定成败** — 闭眼调 = 翻车

---

## 十五、调味的"地雷区"

⚠️ **不要**:

1. **调料全一起下**(一次性加一堆)→ 无法补救
2. **酱油当水倒**(咸到不能吃)
3. **糖加多了再加醋**(乱套了)
4. **葱姜蒜放太多盖过主味**
5. **盖盖子时加醋**(挥发,白加)
6. **出锅前再补盐**(易咸)
7. **过度依赖味精**(掩盖真味)
