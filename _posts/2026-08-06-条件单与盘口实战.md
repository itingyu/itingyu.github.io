> **一句话**:**条件单 = 散户自动化的"交易机器人"**。**3 大类型 = 价格单 / 时间单 / 联动单**。**盘口实战 = 看大单 + 看分时 + 看量能**。**不会看盘 + 不会条件单 = 高频手动 = 必亏**。

---

## 一、集合竞价 3 大时段再精读

| 时段 | 时间 | 挂单? | 撤单? | 实战动作 |
|---|---|:---:|:---:|---|
| **假象期** | 9:15-9:20 | ✅ | ✅ | **不挂单!主力表演期** |
| **真相期** | 9:20-9:25 | ✅ | ❌ | **观察,不轻易出手** |
| **静默期** | 9:25-9:30 | ❌ | ❌ | **复盘集合竞价结果** |

### 1.1 集合竞价 4 大信号

| 信号 | 含义 |
|---|---|
| **高开 + 量缩** | 主力"试盘" → 短期可能下跌 |
| **高开 + 量增** | 真金白银看多 → 强势 |
| **低开 + 量缩** | 正常回调 |
| **低开 + 量增** | 主力出货 → 短期可能继续跌 |

### 1.2 真实案例:2024-10-08 集合竞价骗局(再回顾)

- 9:15-9:20:沪深 300 期货高开 +10%,挂出 100 万手涨停买单
- 9:20-9:25:撤掉 90 万手
- 9:25 撮合价 +4.5%
- 早盘追进的散户 → 被套在短期高点

> 💬 **"9:20 之前挂单 = 放风筝;9:20 之后挂单 = 签字画押。散户只看 9:25 的撮合价,不看 9:15-9:20 的'表演'。"**

## 二、条件单 3 大类型

### 2.1 类型 1:价格条件单

```
触发条件:价格 ≤ X(买入) 或 价格 ≥ Y(卖出)
举例:茅台 1300 元买入 / 1500 元卖出
用途:突破买入 / 跌破止损
```

### 2.2 类型 2:时间条件单

```
触发条件:到指定时间执行
举例:每天 14:55 卖出
用途:尾盘卖出 / ETF 定投
```

### 2.3 类型 3:联动条件单

```
触发条件:股票 A 触发 → 自动买卖股票 B
举例:沪深 300 ETF +1% → 加仓股票池
用途:对冲 / 联动策略
```

## 四、盘口实战 5 大要素

### 4.1 要素 1:委比(委托买卖差)

```
委比 = (委买 - 委卖) / (委买 + 委卖) × 100%
- 委比 > +50% = 买盘强势
- 委比 < -50% = 卖盘强势
- 委比波动大 = 多空博弈
```

### 4.2 要素 2:量比(当下热度)

```
量比 = 现成交量 / 过去 5 日同时段平均
- 量比 > 2 = 放量(关注)
- 量比 > 5 = 巨量(警惕顶部)
- 量比 < 0.5 = 缩量(观望)
```

### 4.3 要素 3:换手率(交易活跃度)

| 换手率 | 含义 |
|---|---|
| **< 1%** | 极低活跃(冷门股) |
| **1-3%** | 正常(健康) |
| **3-7%** | 活跃(关注) |
| **7-15%** | 巨活跃(短期机会 / 风险) |
| **> 15%** | 极端(短期见顶信号) |

### 4.4 要素 4:大单动向(主力)

| 大单 | 含义 |
|---|---|
| **买 1-5 档 100 万+** | 主力吸筹(可能拉升) |
| **卖 1-5 档 100 万+** | 主力出货(可能下跌) |
| **大单持续买入** | 主力护盘 |
| **大单持续卖出** | 主力跑路 |

### 4.5 要素 5:分时图形态

| 形态 | 含义 |
|---|---|
| **均线支撑** | 价格沿均线上涨,强势 |
| **台阶上升** | 一波涨一波横,健康 |
| **倒 V** | 冲高回落,出货 |
| **深 V** | 探底回升,可能反弹 |

## 五、实战看盘:高德红外 8-5 复盘

### 5.1 8-5 关键节点

- **9:30-9:45**:**+5% 高开**(军工板块催化)
- **9:45-10:30**:**+8% 拉升**(板块联动)
- **10:30-11:30**:**+9% 触及涨停**(封板)
- **11:30-13:00**:**+9.5% 封板**(封单 3 亿+)
- **13:00-14:00**:**+8% 开板**(主力出货)
- **14:00-15:00**:**+6% 收尾**(高位震荡)

### 5.2 看盘 5 大关键判断

| 时间 | 信号 | 含义 |
|---|---|---|
| 9:25 | 集合竞价高开 +5% | 主力意图强势 |
| 9:30-10:30 | 持续放量 | 真金白银看多 |
| 11:30 | 封板 3 亿 | 主力控盘 |
| 13:00 | 开板 | 主力开始卖 |
| 14:00 后 | 高位震荡 | 散户接盘 |

### 5.3 散户应对

| 阶段 | 散户行动 |
|---|---|
| 9:25 集合竞价 | **不追!高开常陷阱** |
| 9:30-11:30 拉升 | **错过不追,等待回调** |
| 11:30 封板 | **观察,不轻易开板买** |
| 13:00 开板 | **警惕,主力出货** |
| 14:00 后震荡 | **次日看是否高开** |

> 💬 **"涨停板是双刃剑——主力封板 = 控盘;主力开板 = 出货。散户涨停板追入 = 60% 被套。"**

## 六、5 大常见盘口陷阱

### 6.1 陷阱 1:假突破

```
价格突破阻力位 → 散户追高 → 主力出货 → 价格回落
识别:突破时量缩 = 假突破
```

### 6.2 陷阱 2:放量滞涨

```
价格高位 + 巨量 + 涨幅小 = 主力出货
识别:量增价不涨 = 危险信号
```

### 6.3 陷阱 3:尾盘拉升

```
14:50 后突然拉升 = 主力做收盘价
识别:尾盘无量拉升 = 警惕
```

### 6.4 陷阱 4:跌停吸筹

```
跌停板大单 = 主力可能吸筹
但也可能是主力出货
识别:跌停后次日走势
```

### 6.5 陷阱 5:高换手陷阱

```
高换手 = 高活跃
但高换手也可能是主力对倒
识别:换手 + 价格走势
```

## 九、3 大实战原则

### 9.1 原则 1:不追高

```
高开 +5% 以上 = 不追
高开 + 量增 = 谨慎
高开 + 量缩 = 假强势
```

### 9.2 原则 2:看大单

```
大单 = 主力信号
中单 = 机构信号
小单 = 散户信号
→ 跟主力
```

### 9.3 原则 3:用条件单

```
手工盯盘 = 错过信号
条件单 = 自动化
→ 必备工具
```

> 💬 **"条件单 = 散户的'自动驾驶'。盘口实战 = 看大单 + 看分时 + 看量能。3 大原则 = 不追高 + 看大单 + 用条件单。"**
