# 命名系统（2）：自然科学——从分子到星系

自然科学是命名规则最严密的地方。原因很朴素：这里的对象数量以亿计，而且跨越几百年、几十种语言，如果不靠规则而靠约定，早就乱成一锅粥了。

这一篇按学科拆：化学、生物、天文、地质气象、计量。重点不在罗列名称，而在看清每套规则**把权威放在了哪里**。

## 一、化学：唯一能「算」出名字的学科

### 系统命名法

IUPAC 的取代命名（substitutive nomenclature）本质上是一棵语法树：

- **母体**：最长碳链或主要官能团所在的骨架
- **后缀**：决定化合物类别（-ol 醇、-oic acid 酸、-amine 胺）
- **取代基前缀**：谁挂在上面（甲基、氯、羟基）
- **定位数**：挂在第几个位置

`2,2-二甲基丙烷` 就是这么长出来的：母体丙烷（3 个碳），2 号碳上挂两个甲基。给结构式，任何人按规则推导，得到的名字唯一。

这套规则强到可以反过来解析。化学信息学软件做「名称 → 结构」的逆向推导，靠的就是 IUPAC 的语法。

代价有两个：

1. **长度爆炸**。中等复杂度的天然产物，系统名能写满三行。
2. **历史名抢跑**。阿司匹林、咖啡因、吗啡这些名字早于规则，且被法规和商业固化，系统名反而没人用。IUPAC 对此的妥协是设立 PIN（Preferred IUPAC Name），在保留名和系统名之间指定一个「首选」。

### 登记体系：CAS、InChI、SMILES

语法名太长，数据库不能拿它当主键。于是有了三套并行的编码：

| 体系 | 形态 | 特点 |
|:--|:--|:--|
| CAS 登记号 | `7732-18-5` | 纯流水，权威发号，永不复用 |
| InChI | `InChI=1S/H2O/h1H2` | 由结构算法生成，可逆，有标准 |
| InChIKey | `XLYOFNOQVPJJNP-UHFFFAOYSA-N` | InChI 的哈希，27 字符，适合做索引 |
| SMILES | `O` | 简洁，但**同一分子有多种写法**，不能当唯一键 |

关键区别：SMILES 是给人写的，InChI 是给机器算的。前者写法自由，后者有严格的标准化流程（规范化、去冗余、固定层结构）。

CAS 号带校验位，算法简单：取校验位之前的数字，从右往左依次乘 1、2、3……求和，模 10 应等于校验位。

以水 `7732-18-5` 为例：

```python
def cas_check(body: str) -> int:
    total = sum(int(ch) * (i + 1) for i, ch in enumerate(reversed(body)))
    return total % 10

print(cas_check("773218"))   # 5
```

`8×1 + 1×2 + 2×3 + 3×4 + 7×5 + 7×6 = 105`，`105 % 10 = 5`，与末位一致。

### 一个物质，几个号

以乙醇为例：

- IUPAC 名：ethanol
- CAS 号：64-17-5
- EC 号：200-578-6（欧盟现有物质目录）
- UN 编号：1170（危险货物运输）
- HS 编码：2207.10（关税）

五个号，五种用途，互不替代。这是「命名系统」最容易被误解的地方——**以为存在一个万能编号，其实每个体系只解决自己那段流程**。

## 二、生物：三百年前定下的规则

### 双名法

林奈在 1753 年《植物种志》和 1758 年《自然系统》第十版里定下的格式，至今没变：

```
属名 + 种加词 + 命名人, 年份
Panthera leo (Linnaeus, 1758)
```

规则细节：

- 拉丁化，斜体，属名首字母大写，种加词全小写
- 亚种用三名：`Canis lupus familiaris`
- 命名人加括号表示属已变更：狮子原本归于 Felis，所以 Linnaeus 带括号
- 名称的锚点是**模式标本**（type specimen），不是描述、不是照片

最后一条是整个体系的根基。名字之所以不会漂移，是因为它绑定在一个具体的、可复查的实物上。任何人怀疑某个名字指的不是这个东西，就去调模式标本。

### 四部法规，各管一片

| 类群 | 法规 | 起点 |
|:--|:--|:--|
| 藻类、真菌、植物 | ICN | 1753（林奈《植物种志》） |
| 动物 | ICZN | 1758（《自然系统》第 10 版） |
| 原核生物 | ICNP | 1980-01-01（Approved Lists） |
| 病毒 | ICTV | 不适用双名法传统，2020 年后引入双名种名 |

四部法规互不干涉，所以同名可以跨类群存在——`Aotus` 既是豆科植物属，也是一类夜猴。跨类群检索必须带上类群限定。

### 优先律与例外

规则的核心是优先律：**最早合格发表的名字有效**。合格发表要满足：有拉丁文描述（2012 年后英文也可）、指定模式、在合规出版物上发表、符合双名法格式。

优先律带来一个副作用：老文献里的名字经常被推翻。所以分类学论文里，学名后面常跟一串异名（synonymy），把历史上的叫法都列出来，方便对账。

## 三、基因与蛋白：一套并行的命名

基因命名是另一条线，和物种命名互不影响。

- **HGNC 基因符号**：人类基因用全大写斜体 `TP53`、`BRCA1`；蛋白用正体 `p53`
- **物种前缀**：人类无前缀；小鼠基因首字母大写 `Trp53`；果蝇、酵母各有约定
- **登录号**：UniProt `P04637`、NCBI Gene ID，这些才是数据库主键

基因符号的最大问题是重名和别名。同一个基因在文献里可能有五六个叫法，所以 HGNC 维护一张同义词表，官方符号只有一个。

**EC 号**是酶的另一套编码，四段式：

```
EC 1.1.1.1
   │ │ │ └─ 具体酶
   │ │ └─── 亚亚类
   │ └───── 亚类
   └─────── 大类（1 氧化还原酶、2 转移酶、3 水解酶、4 裂合酶、5 异构酶、6 连接酶、7 转位酶）
```

和基因符号一样，EC 号也在不断修订、拆分、合并，所以文献里必须写版本或年份。
## 四、天文：命名权集中在 IAU

天文的命名权高度集中。国际天文学联合会（IAU）1919 年成立后，逐步收拢了各路命名权。

### 恒星：两套老编号

- **Bayer 命名**：希腊字母 + 星座属格，`α Centauri`。1603 年拜耳提出，按亮度排（后来发现并不严格）
- **Flamsteed 命名**：数字 + 星座属格，`61 Cygni`。数字按赤经顺序
- 两者都会因为星座边界和亮度修订而显得不合逻辑，但已经用了几百年，不改

### 深空天体：星表号

| 星表 | 例子 | 说明 |
|:--|:--|:--|
| 梅西耶 | M31 | 110 个，18 世纪为找彗星而编 |
| NGC | NGC 224 | 1888 年 Dreyer 编，7840 个 |
| IC | IC 1101 | NGC 的补编 |

同一个天体常有多个号：仙女座星系 = M31 = NGC 224。跨星表映射是天文数据库的基本功。

### 新天体：编号在前，命名在后

小行星发现后先给临时编号（如 `2023 AB1`），确认轨道后给永久编号（如 `(433) Eros`），再由发现者提议名字，IAU 小天体命名委员会（WGSBN）审核。

规则里有几条硬杠：

- 不得以在世人物命名
- 政治、军事人物需逝世 100 年后
- 名字不得买卖（市面上「买一颗星星命名」的商业行为，IAU 一律不承认）

系外行星的规则更简单：宿主恒星名 + 小写字母，`51 Pegasi b`、`TRAPPIST-1e`。字母顺序基本按发现顺序，b 通常是最先发现的。

## 五、地质与气象：靠委员会开会

### 矿物

新矿物要向 IMA 矿物命名与分类委员会（CNMNC）申报，批准后才算数。规则包括：

- 优先权：先发表且描述完整者得名
- 不得以发现者本人命名（这条常被讨论，实际执行有弹性）
- 名字要有词源说明（人名、地名、成分、性质）

目前 IMA 认可的矿物约 6000 种，每年新增几十种，全部有档案可查。

### 地层

地层单位是严格的层级：

```
宇 Eonothem → 界 Erathem → 系 System → 统 Series → 阶 Stage
```

显生宙、中生界、白垩系、上统、马斯特里赫特阶——每一级都有全球层型剖面和点位（GSSP，俗称「金钉子」）作为物理锚点。这和生物命名里的模式标本是同一个思路：**名字必须钉在实物上**。

### 台风

西北太平洋的台风命名表由 WMO 台风委员会维护：

- 14 个成员各提供 10 个名字，共 140 个
- 按顺序循环使用，同时给编号：`2305` = 2023 年第 5 号
- 造成重大灾害的台风名字会被**除名**，由提供方补一个新名字

所以「海燕」「山竹」这些名字已经从表里消失。除名机制的本质是：避免灾难名反复出现造成混淆和情感伤害。

## 六、计量：可推导的命名

SI 单位是语法生成式的另一个典型：7 个基本单位（m、kg、s、A、K、mol、cd），导出单位由代数式组合（m/s、kg·m/s²），不需要逐个命名。

词头也是规则的：`k` 10³、`M` 10⁶、`G` 10⁹；小数侧 `m` 10⁻³、`μ` 10⁻⁶、`n` 10⁻⁹。2022 年新增了四个极端词头：`Q` quetta 10³⁰、`R` ronna 10²⁷、`r` ronto 10⁻²⁷、`q` quecto 10⁻³⁰。

符号的大小写有硬规则：单位符号一般小写，源自人名的首字母大写（Pa、Hz、N），升的符号可以是 `L` 或 `l`，这是历史遗留的例外。

## 七、这一行的共同点

自然科学的命名体系，几乎都靠三件套维持秩序：

1. **一个权威机构**：IUPAC、ICZN、IAU、IMA、WMO
2. **一部可修订的法规**：规则本身有版本，几年一改
3. **一个物理锚点**：模式标本、金钉子、标准物质

第三条最容易被忽视，却最关键。没有锚点，名字就只是描述，描述会随认识变化，名字也就跟着漂。有了锚点，哪怕分类修订、属名更换，指的还是那个东西。
