# 01 · 厨房原理总论

> 烹饪的"理"先于"技"。理解了底层原理,任何菜谱都能举一反三。

---

## 一、烹饪的本质

烹饪 = **热处理 + 调味 + 成形**

- **热处理**:通过加热改变食材的物理状态(软化、凝固)和化学结构(褐变、糊化)
- **调味**:通过盐、糖、酱、香料让味蕾产生愉悦感
- **成形**:刀工与烹法决定最终的"口感"与"卖相"

一句话概括:**烹饪是控制"食材—热量—调味"三者关系的艺术。**

---

## 二、热量传递的三种方式

| 方式 | 原理 | 在厨房的应用 |
|---|---|---|
| **传导** | 热量从高温向低温物体直接传递 | 锅底把热量传给食材 |
| **对流** | 流体(油/水/空气)流动传热 | 煮汤时水的翻滚、炒菜时油的循环 |
| **辐射** | 高温物体以电磁波形式发散热量 | 烤箱、明火烤、微波 |

### 实际意义

1. **炒锅传热最快** → 适合爆炒
2. **砂锅传热慢但均匀** → 适合慢炖
3. **金属烤盘导热快** → 适合快速煎烤
4. **油比水传热快** → 油炸比水煮"温度更高"

## 三、食材的化学组成

**理解食材 = 理解水/蛋白/脂肪/糖/纤维五大组分**。

| 组分 | 含量参考 | 受热变化 | 在烹饪中的作用 |
|---|---|---|---|
| **水** | 蔬菜 80-95%,肉类 60-75% | 蒸发/渗出 | 决定嫩度,失水=变老 |
| **蛋白质** | 肉 15-25% | 变性(凝固),60℃起,70-80℃ 大量出水,较高→150℃褐变 | 决定肉质的紧实度 |
| **脂肪** | 五花肉 50%,瘦肉 5% | 融化、乳化 | 提供风味载体(脂溶香) |
| **糖类** | 主食、米面 | 糊化(60-80℃)、焦糖化(>140℃) | 决定甜味与焦香 |
| **纤维** | 蔬菜、全谷 | 软化 | 决定口感脆/软 |
| **矿物质/维生素** | 蔬果 | 易流失(尤其水溶) | 影响营养 |

## 四、四个核心化学反应

### 1. 美拉德反应(Maillard Reaction)
- **条件**:温度>140℃,需要氨基酸 + 还原糖,**无水环境**
- **结果**:产生**上百种风味物质**,形成褐色表层
- **典型应用**:煎牛排、烤面包、炒糖色、煎鱼
- **关键变量**:
  - 温度越高,反应越快(超过 180℃ 容易焦苦)
  - **不能有水** → 一旦有水,温度被限制在 100℃,无法发生美拉德
- **厨房启示**:**想要焦香 → 必须先煎干表面水分**

### 2. 焦糖化反应
- **条件**:糖 + 温度 > 160℃
- **结果**:蔗糖 → 多种芳香物质 + 褐色色素
- **典型应用**:拔丝、糖醋、炒糖色、烤布丁
- **阶段**:
  - 140-150℃:糖融化
  - 160-170℃:浅黄,香甜
  - 180℃:深琥珀色,焦香浓郁 ←**做糖色的最佳阶段**
  - >190℃:发苦发黑(失败)

### 3. 淀粉糊化
- **条件**:淀粉 + 水 + 加热(60-80℃ 起)
- **结果**:淀粉粒膨胀破裂,黏度增加
- **典型应用**:勾芡、煮饭、熬粥、做羹
- **厨房启示**:
  - **勾芡前淀粉要加冷水调开**(热水直接入锅会结块)
  - **勾芡要分次少量**,一次下太多会太稠

### 4. 蛋白质变性(meat tender/vegetable softening)
- **条件**:温度、pH、盐、金属离子都可引发
- **结果**:蛋白质结构改变,变得紧实
- **典型应用**:煮蛋、肉类收紧、豆浆→豆腐
- **嫩肉三大原理**:
  - **盐腌**:渗透压让肉纤维吸收水分(钠离子打破蛋白网络)
  - **碱嫩**:小苏打/碱水提高 pH,肉质松散(易过量发碱味)
  - **物理敲打**:断纤维、增大表面积

## 五、其他关键原理

### 乳化(Emulsion)
- **定义**:油和水本不相溶,通过**乳化剂**(蛋黄、芥末、糖)把油滴稳定地分散在水里
- **典型应用**:蛋黄酱、奶白鱼汤、油醋汁、麻酱
- **原理**:
  - 蛋黄含卵磷脂(乳化剂)
  - 鱼汤变白 = 脂肪被沸腾水乳化成无数小油滴
  - 麻酱澥开 = 加少量水或油反复搅拌

### 渗透与扩散
- **腌菜**:盐浓度差 → 蔬菜出水变软 → 盐味进入菜里
- **糖渍水果**:糖渗透进水果 → 析出水分,蜜饯形成
- **卤肉**:香料分子扩散进入肉纤维

### pH 值的厨房应用
- **加醋保脆**:醋酸抑制果胶酶,蔬菜更脆(凉拌菜)
- **加醋软化鱼骨**:醋溶出鱼骨中的钙
- **加碱嫩肉**:碱性环境松散蛋白(豆腐嫩滑)
- **加酒去腥**:酒精溶解腥味物质并挥发

### 油温与沸点
- **油的沸点**:200-300℃(种类不同)
- **水的沸点**:100℃(标准大气压下,加入盐糖会略升)
- **油温升高让水分瞬间蒸发** → **油炸的酥脆就是这原理**

## 六、热源与锅具的"性格"

### 锅具

| 锅 | 材质 | 性格 | 适合 |
|---|---|---|---|
| **铁锅** | 生铁/熟铁 | 储热强,升温快,需开锅养锅 | 爆炒、煎 |
| **不粘锅** | 涂层 | 不粘、易用,但不耐高温刮擦 | 煎鱼、煎蛋、新手 |
| **不锈钢锅** | 18/10 钢 | 受热均匀,但易粘 | 煮汤、炖煮 |
| **砂锅/陶锅** | 陶土 | 储热强,密封性好 | 煲汤、炖菜、焖肉 |
| **铝锅** | 铝 | 导热极快,但不耐强碱 | 一般不推荐 |
| **铜锅** | 铜 | 导热极快,价格贵 | 高级料理 |

### 热源

| 热源 | 特点 |
|---|---|
| **燃气** | 火大可调,明火有锅气,适合中式爆炒 |
| **电磁炉** | 只加热铁质锅底,无明火,温度均匀 |
| **电陶炉** | 红外线,可配陶瓷锅 |
| **微波** | 水分子共振,内部加热,但无法形成美拉德 |
| **烤箱** | 空气对流+辐射,适合烘烤 |

## 七、风味的两大机制

1. **味觉**:舌头尝到的味道(甜咸酸苦鲜)
2. **嗅觉**:鼻子里闻到的香气(几百种风味分子)

**关键认知**:风味的 70-80% 来自**嗅觉**,不是味觉。

- **感冒鼻塞时吃饭没味道** → 验证了这一点
- **菜冷了不香** → 温度低,香气分子挥发少 → 重新加热可恢复
- **香辛料(葱姜蒜八角)** → 都是脂溶性香气分子,需要油脂或酒精激发

## 九、本章核心结论

| 认知 | 应用 |
|---|---|
| **美拉德需要高温+无水** | 想焦香 → 先煎干表面 |
| **油温 > 水温** | 油炸比水煮温度高,能形成脆壳 |
| **蛋白质 60℃ 变性,80℃ 收紧** | 想嫩 → 低温短时间 / 想老 → 高温长时间 |
| **糖 160-180℃ 焦糖化** | 糖色在这温度区间最香 |
| **风味的 80% 来自嗅觉** | 重视香气的激发(热油浇葱花、热炒姜蒜) |
| **乳化靠乳化剂** | 蛋黄酱、奶白汤都靠它 |
| **pH 影响口感** | 加醋保脆,加碱嫩肉 |
