> **一句话**:**逆向投资 = 别人贪婪我恐惧,别人恐惧我贪婪**。**情绪温度 4 阶段:绝望 → 怀疑 → 乐观 → 狂热**。**抄底要在绝望期,减仓要在狂热期**。**不懂情绪面 = 永远在追涨杀跌**。

---

## 一、A 股情绪 4 阶段(逆向投资的核心)

### 1.1 情绪温度计

| 阶段 | 情绪 | 表现 | 操作 |
|---|---|---|---|
| **绝望期** | 10° | 没人谈股,跌到麻木 | **建仓** ⭐ |
| 怀疑期 | 30° | 反弹了也不敢买 | 分批加仓 |
| 乐观期 | 60° | 开始有人讨论股票 | 持有 |
| **狂热期** | 90° | 所有人都在谈股,排队开户 | **减仓** 🚩 |

> 💬 **"在别人贪婪时恐惧,在别人恐惧时贪婪——这是逆向投资的全部秘密。"**

### 1.2 A 股 2024-2026 真实历程

| 时间 | 阶段 | 关键事件 |
|---|---|---|
| 2024-01 | 绝望 | 雪球敲入,2635 点 |

| 2025-09 | 狂热延续 | 创业板 Q3 +50% |

## 二、5 大情绪仪表盘指标(量化情绪)

### 2.1 指标 1:两市成交额

| 区间 | 含义 |
|---|---|
| < 6000 亿 | 绝望期(底部信号) ⭐ |
| 6000-10000 亿 | 正常 |
| 10000-15000 亿 | 偏热 |
| > 15000 亿 | 狂热期(顶部信号) 🚩 |

### 2.2 指标 2:融资余额

| 变化 | 含义 |
|---|---|
| 持续下降 | 绝望(去杠杆) |
| 月增 10-20% | 偏热 |
| 月增 50%+ | 狂热(高风险)🚩 |

### 2.3 指标 3:北向资金

| 方向 | 含义 |
|---|---|
| 持续净卖出 | 绝望(外资跑) |
| 平衡 | 正常 |
| 持续净买入 | 偏热 |
| 单日暴买 | 狂热信号 |

### 2.4 指标 4:ETF 净流入

| 变化 | 含义 |
|---|---|
| 持续净流出 | 绝望 |
| 持续净流入 | 偏热 |
| 单日暴入 | 狂热信号 |

### 2.5 指标 5:新开户数

| 月开户 | 含义 |
|---|---|
| < 100 万 | 绝望 |
| 100-200 万 | 正常 |
| 200-400 万 | 偏热 |
| > 400 万 | **狂热** |

**真实案例**:
- 2024-10 单月开户 **684.68 万户**(历史第三)→ 狂热信号
- 2024 年 10-12 月开户合计占全年 **46.14%**→ 散户跑步入场

## 三、实战判断框架

```
看 5 大指标 → 3 个以上偏冷 = 绝望期(逆向建仓)
              1-2 个偏冷/正常 = 怀疑期(分批加仓)
              1-2 个偏热 = 乐观期(持有)
              3 个以上偏热 = 狂热期(减仓)
```

## 五、逆向投资的 5 大原则

### 5.1 原则 1:人多的地方不去

```
2024-10 散户跑步入场 = 顶部信号
→ 别人贪婪我恐惧
```

### 5.2 原则 2:人少的地方有金矿

```
2024-01 2635 点无人问津 = 底部信号
→ 别人恐惧我贪婪
```

### 5.3 原则 3:左侧建仓 + 右侧确认

```
左侧:绝望期开始建仓(越跌越买)
右侧:突破关键位加仓(趋势确认)
```

### 5.4 原则 4:逆向 ≠ 逆势

```
🚩 逆势:大盘下跌时买弱势股(找死)
✅ 逆向:大盘下跌时买抗跌的优质股(机会)
```

### 5.5 原则 5:基本面 + 情绪面双重验证

```
只看情绪:可能抄底到无底洞
只看基本面:错过最佳时机
双重验证:绝望期 + 优质股 = 最佳买点
```

## 六、4 大实战案例

### 6.1 2024-01 雪球敲入(绝望)

- 2024-01-22 中证 1000 跌 5%
- 雪球 4 倍杠杆产品敲入
- 散户恐慌割肉
- **底部信号**:融资余额 / 成交额 / 散户情绪 3 项全冷
- **逆向操作**:1 月底建仓,持有到 9 月

### 6.2 2024-09 924 行情(怀疑→乐观)

- 9-24 沪指 +4.15%, 创业板 +10%
- 央行 1.8 万亿增量
- 5 大指标:成交 / 融资 / 散户 / 北向 全面转热
- **操作**:加仓,把握政策窗口

### 6.3 2024-10 散户跑步入场(狂热)

- 10 月单月开户 685 万(历史第三)
- 10-12 月开户占全年 46.14%
- 成交突破 2 万亿
- **顶部信号**:3 项指标狂热
- **操作**:开始减仓

### 6.4 2025-08 沪指 10 年新高(狂热延续)

- 沪指突破 3500 点
- 牛市进入中段
- **操作**:继续减仓,留 30% 底仓

> 💬 **"逆向投资不是'反着干',是'用情绪指标量化操作'。5 大指标 + 4 阶段 = 抄底逃顶的'温度计'。"**
