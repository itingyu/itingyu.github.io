### 1.2 雪球敲入的传导链

```

   ↓

   ↓

私募强平(被动卖)
   ↓
散户恐慌割肉
```

## 五、底部建仓的 3 大纪律

### 5.1 纪律 1:金字塔加仓

```
底仓 30% → 反弹 + 10% 加仓 20% → 突破 + 20% 加仓 20%
→ 不倒金字塔(越涨越买 ≠ 越涨越卖)
```

### 5.2 纪律 2:左侧 + 右侧结合

```
左侧(绝望期):底仓 30%
右侧(突破):确认后加仓
→ 兼顾早入场 + 风险控制
```

### 5.3 纪律 3:行业选择

```
底部反转时,优先选择:
1. 政策直接受益(金融 / 地产)
2. 估值最低(PB < 1)
3. 高股息(防御性)
```

## 六、底部反转的 4 大教训

### 6.1 教训 1:杠杆产品必死

```
雪球 / 期权 / 期货 / 融资 = 1 次敲入归零
→ 散户唯一正确:不参与
```

### 6.2 教训 2:不抄底"看着便宜"的票

```
2635 点时,很多 PB 0.5 的票
→ 但很多是价值陷阱
→ 只买 PB < 1 + ROE > 15% 的优质票
```

### 6.3 教训 3:底部不是一天

```
2635 点是 1-2 月,924 是 9 月
→ 8 个月的"绝望期"
→ 散户要熬得住
```

### 6.4 教训 4:不加杠杆抄底

```
想"抄底更快"加杠杆
→ 雪球敲入归零
→ 底部是熬出来的,不是杠杆加出来的
```
