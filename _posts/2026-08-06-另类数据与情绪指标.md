> **一句话**:**另类数据 = 不靠财报的"先行指标"**。**3 大类:卫星图像 / 信用卡 / 舆情**。**量价是 A 股最强情绪指标**。**散户用另类数据 = 提前 1-3 个月知道拐点**。

---

## 一、什么是另类数据

### 1.1 一句话

```
另类数据 = 不在财报 / 公告里的数据
         = 卫星 / 信用卡 / 舆情
         = 提前 1-3 个月的"先行指标"
```

### 1.2 传统数据 vs 另类数据

| 维度 | 传统数据 | 另类数据 |
|---|---|---|
| 来源 | 财报 / 公告 | 卫星 / 信用卡 / 舆情 |
| 频率 | 季度 | 实时 / 日 |
| 时效 | 滞后 1-3 月 | 实时 |
| 门槛 | 低 | 高(技术) |

---

## 二、3 大另类数据

### 2.1 类型 1:卫星图像(看实体经济)

#### 2.1.1 港口货运(看进出口)

```
- 卫星拍港口
- 算集装箱数量
- → 进出口景气度
- 领先 PMI 1-2 个月
```

**真实案例**:
- 2024-Q3 上海港集装箱数量 -8%
- → 出口走弱
- → 2024-12 PMI 跌至 49
- 卫星数据领先 2 个月

#### 2.1.2 油罐库存(看油价)

```
- 卫星拍油罐
- 算影子长度 → 油罐储量
- → 原油库存变化
- 领先 EIA 数据 1 周
```

#### 2.1.3 商场停车场(看消费)

```
- 卫星拍商场停车场
- 算车辆数
- → 商场客流
- 领先社零 2 周
```

#### 2.1.4 钢厂高炉(看钢铁)

```
- 卫星拍钢厂
- 看高炉是否开工
- → 钢铁产量
- 领先统计局 2 周
```

### 2.2 类型 2:信用卡(看消费)

#### 2.2.1 信用卡消费总额

```
- 美国:Capital One / Chase 信用卡
- 中国:招商 / 平安 / 中信 信用卡
- 消费数据 = 零售先行指标
- 领先社零 2-4 周
```

#### 2.2.2 航空订票(看出行)

```
- Expedia / Booking / 携程
- 订票数据 = 旅游景气度
- 领先民航局数据 1-2 周
```

#### 2.2.3 外卖订单(看消费)

```
- 美团 / 饿了么
- 订单数据 = 餐饮景气度
- 领先餐饮收入 2 周
```

#### 2.2.4 真实案例

- **2024-12 信用卡消费总额 -3%**
- **2025-Q1 社零 -1%**
- **2025-04 消费板块下跌 5%**
- 信用卡数据领先 2 个月

### 2.3 类型 3:舆情(看情绪)

#### 2.3.1 社交媒体(看散户情绪)

```
- 微博 / 雪球 / 股吧
- 关键词频率
- → 散户情绪指标
- 领先市场 1-2 周
```

**3 大情绪指标**:
| 指标 | 含义 | 阈值 |
|---|---|---|
| **散户情绪温度** | 关键词 / 讨论量 | > 80 = 狂热,顶部 |
| **新开户数** | 新增 A 股账户 | > 400 万/月 = 顶部 |
| **"牛市"搜索** | 百度指数 | > 10000 = 关注 |

#### 2.3.2 新闻舆情(看政策预期)

```
- 财经媒体 / 政策吹风
- NLP 分析情绪
- → 政策预期
- 领先政策 1-2 周
```

#### 2.3.3 真实案例

- **2024-10 散户情绪温度 85(狂热)**
- **新开户 685 万(历史第三)**
- **"牛市"搜索 +500%**
- → **2024-10 中下旬短期顶部**
- 舆情指标领先 2 周

> 💬 **"舆情 = 市场情绪的'温度计'。散户开户暴增 = 顶部信号。"**

## 三、量价分析(A 股最强情绪指标)

### 3.1 量价 4 字真言

```
放量上涨 = 强势 → 持有
放量下跌 = 出货 → 减仓
缩量上涨 = 拉高出货 → 警惕
缩量下跌 = 正常调整 → 关注是否止跌
```

### 3.2 量价 5 大经典形态

| 形态 | 含义 | 操作 |
|---|---|---|
| **量增价升** | 主力吸筹 | 持有 |
| **量增价平** | 主力出货(精华 14 P31 信号) | **减仓** |
| **量缩价升** | 主力拉升末期 | 警惕 |
| **量缩价跌** | 抛压减弱 | 关注 |
| **天量天价** | 顶部信号 | **卖出** |

### 3.3 量价 3 大实战

#### 3.3.1 实战 1:底部放量

```
- 价格底部 + 成交量放大 + 上涨
- 主力吸筹信号
- 买入
```

#### 3.3.2 实战 2:顶部放量

```
- 价格高位 + 成交量放大 + 滞涨
- 量增价平 = 出货
- 卖出
```

#### 3.3.3 实战 3:缩量上涨

```
- 价格上涨 + 成交量缩小
- 主力拉升末期
- 警惕
```

### 3.4 量价指标 4 件套

| 指标 | 含义 |
|---|---|
| **成交量** | 当日成交股数 |
| **换手率** | 交易活跃度 |
| **量比** | 当下 vs 5 日同时段平均 |
| **OBV** | 能量潮,看资金进出 |

## 四、3 大另类数据 + 量价的实战组合

### 4.1 组合 1:卫星 + 量价

```
- 卫星看港口货运
- 量价看资金进出
- → 判断进出口板块拐点
```

### 4.2 组合 2:信用卡 + 量价

```
- 信用卡看消费
- 量价看消费股
- → 判断消费板块拐点
```

### 4.3 组合 3:舆情 + 量价

```
- 舆情看散户情绪
- 量价看主力动向
- → 判断顶部 / 底部
```

## 五、3 大实战案例

### 5.1 案例 1:2024-09 924 行情

- 舆情:政策吹风 + 媒体大量报道
- 信用卡:消费数据回暖
- 量价:9-24 巨量 + 沪指 +4.15%
- 组合信号:**底部 + 启动**
- 操作:**建仓**

### 5.2 案例 2:2024-10 顶部

- 舆情:散户情绪 85(狂热)
- 信用卡:消费数据已透支
- 量价:巨量滞涨
- 组合信号:**顶部**
- 操作:**减仓**

### 5.3 案例 3:2025-09 创业板顶部

- 舆情:科技主题热
- 信用卡:消费降级
- 量价:Q3+50% 后缩量
- 组合信号:**成长股顶部**
- 操作:**减仓**

## 六、3 大实战建议

### 6.1 建议 1:用舆情 + 量价

```
散户情绪温度 + 量价异动
= 顶部 / 底部信号
```

### 6.2 建议 2:用信用卡 + 卫星

```
信用卡 + 卫星
= 消费 / 进出口拐点
```

### 6.3 建议 3:用另类数据交叉验证

```
单一数据 = 可能骗
3 大数据交叉 = 准
```

## 七、3 大局限

### 7.1 局限 1:数据门槛高

```
- 卫星图像 = 需要付费
- 信用卡数据 = 需要 API
- 舆情分析 = 需要 NLP
- 散户难直接用
```

### 7.2 局限 2:不是"圣杯"

```
- 另类数据只是"先行指标"
- 不是"决定性"
- 要结合其他分析
```

### 7.3 局限 3:政策市 A 股的特殊性

```
- A 股政策影响大
- 另类数据可能失效
- 必须结合政策
```

> 💬 **"另类数据 = 卫星 + 信用卡 + 舆情,领先 1-3 个月。量价 = A 股最强情绪指标。3 大组合:舆情+量价、信用卡+卫星、舆情+信用卡。散户用门槛高,但能看'先知'信号。"**
