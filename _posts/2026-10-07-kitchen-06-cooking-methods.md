# 06 · 烹饪方法

> 烹饪法 = 不同的"温度场 + 时间 + 处理顺序"组合。掌握每种方法的核心逻辑,任何菜都能拆解。

---

## 一、炒(Stir-fry)

> **核心**:高温 + 快 + 少油 + 持续翻动

### 分类

| 类型 | 火力 | 油量 | 时间 | 典型菜 |
|---|---|---|---|---|
| **生炒** | 大 | 中 | 短 | 青椒炒肉 |
| **熟炒** | 中 | 中 | 中 | 番茄炒蛋 |
| **滑炒**(软炒) | 中 | 多 | 短 | 滑蛋虾仁 |
| **清炒** | 大 | 中 | 短 | 清炒时蔬 |
| **爆炒** | 大 | 中 | 极短 | 爆炒腰花、宫保鸡丁 |
| **干煸** | 中 | 少 | 长 | 干煸豆角 |

### 通用流程

```
热锅 → 冷油(润锅) → 油热 → 葱姜蒜爆香 →
→ 下主料 → 急火快炒 → 加配菜 → 调味 → 出锅
```

### 关键细节

1. **热锅冷油**:锅先烧热,再倒油,防粘
2. **油温**:爆香葱姜蒜要 150℃+,下主料看食材
3. **滑油**:肉丝/虾仁先过油变白,再回锅(嫩)
4. **出锅时机**:蔬菜断生即出锅(颜色鲜亮、口感脆)

### 防失败

- **糊锅**:锅没烧热,或油太少
- **出水**:火不够大,盐加太早,水未沥干
- **肉老**:滑炒没上浆,或炒太久
- **菜腥**:没加料酒/姜,或油温不够

---

## 二、煎(Pan-fry)

> **核心**:中火 + 油少量 + 单面定型再翻

### 类型

| 类型 | 火力 | 油量 | 适用 |
|---|---|---|---|
| **干煎** | 小-中 | 极少 | 煎带鱼(挂面糊) |
| **油煎** | 中 | 中 | 煎饺子、煎蛋 |
| **半煎炸**(煎炸) | 中 | 多(半没食材) | 锅贴、煎藕盒 |
| **嫩煎** | 小 | 中 | 鸡胸、鱼排 |

### 通用流程

```
锅烧热 → 油(薄薄一层) → 油温合适 →
→ 食材下锅 → 不动,等定型 → 翻面 → 出锅
```

### 关键细节

1. **热锅凉油**:防粘关键
2. **不要早翻**:底部金黄再翻(虾仁变红、蛋边缘凝固)
3. **盖盖子**:嫩煎时盖盖,焖熟内部
4. **中小火**:保持外金黄内嫩

### 适合

- **煎蛋**(太阳蛋、荷包蛋、蛋饼)
- **煎鱼**(鲈鱼、鳕鱼)
- **煎饺/锅贴**(冰花煎饺)
- **煎饼**(葱油饼、煎饼果子)

---

## 三、炸(Deep-fry)

> **核心**:大量油 + 控温 + 分次炸

### 类型

| 类型 | 处理 | 典型 |
|---|---|---|
| **清炸** | 原料腌好直接炸 | 炸里脊、炸鸡块 |
| **干炸** | 裹干粉(淀粉) | 干炸丸子 |
| **软炸** | 挂蛋糊(蛋+水淀粉) | 软炸虾仁 |
| **酥炸** | 蛋液 + 面包糠 | 炸猪排 |
| **脆炸** | 水+面粉糊(脆浆) | 炸蘑菇、炸茄盒 |
| **二次炸** | 先低温定型,再高温上色 | 炸薯条、炸鸡 |

### 通用流程

```
油烧到合适温度 → 食材下锅 →
→ 一次炸定型 → 捞出控油 → 二次炸上色
```

### 油温与时间

| 食材 | 油温 | 时间 |
|---|---|---|
| 花生米 | 五成 (150℃) | 3-5 分钟 |
| 虾 | 六成 (170℃) | 1-2 分钟 |
| 鸡块 | 六成 (170℃) | 5-8 分钟 |
| 薯条 | 五成定型 + 七成上色 | 3+2 分钟 |
| 春卷 | 五成 (150℃) | 3-4 分钟 |
| 鱼 | 六成 (170℃) | 5-7 分钟 |

### 关键细节

1. **食材擦干**:防溅
2. **分批下锅**:不要一次倒太多(降温)
3. **翻动**:让食材受热均匀
4. **控油**:漏勺捞出沥干
5. **复炸**:让外壳更脆(关键!)
6. **油变黑**:换新油(氧化影响健康)

### 安全

- **油锅不能加水**(爆炸)
- **食材含水量大** → 先擦干
- **油温过高冒烟** → 关火降温
- **油锅起火** → **盖锅盖**(别泼水)

---

## 四、煮(Boil/Poach/Simmer)

> **核心**:水或汤 + 加热 + 调味

### 类型

| 类型 | 温度 | 适用 |
|---|---|---|
| **水煮**(沸腾) | 100℃ | 煮面、煮饺子 |
| **汆(Cuān)** | 80-95℃ | 汆丸子、汆羊肉 |
| **白灼**(Zhú) | 80-95℃ | 白灼虾、白灼芥蓝 |
| **清炖** | 85-95℃ 微沸 | 鸡汤、骨汤 |
| **水煮**(川式) | 100℃ 油汤 | 水煮鱼、水煮肉片 |

### 通用流程

```
水/汤烧开 → 下主料 → 控制时间 → 调味 → 出锅
```

### 关键细节

1. **水量**:汤菜 1:2-3,煮面 1:5-8
2. **下锅**:
   - **冷水下锅**:排骨、骨头、整鸡(去血水)
   - **沸水下锅**:饺子、面条、青菜(快速定型)
3. **浮沫**:炖汤时撇去(杂质和血水)
4. **调味**:
   - 一次性加:酱骨头、炖汤
   - 分次加:涮肉、水煮鱼
5. **盐**:汤菜出锅前 10 分钟加(早加汤浑、肉柴)

### 适合

- **汤类**:鸡汤、骨汤、罗宋汤
- **煮面**:面条、米线、粉丝
- **水饺、馄饨**:沸水下、点 3 次水
- **火锅**:随时涮

---

## 五、蒸(Steam)

> **核心**:蒸汽加热,保留原味和营养

### 类型

| 类型 | 工具 | 火力 |
|---|---|---|
| **清蒸** | 蒸笼、蒸锅 | 大火 |
| **粉蒸** | 米粉裹食材 | 大火 |
| **包蒸** | 荷叶、菜叶包 | 大火 |
| **扣蒸** | 碗扣盘 | 大火 |

### 通用流程

```
水烧开(大火) → 食材摆盘/腌好 →
→ 上蒸笼(留间距) → 盖盖 → 计时 → 出锅 → 浇汁
```

### 蒸制时间

| 食材 | 时间 |
|---|---|
| 鱼(整,500-700g) | 8-12 分钟 |
| 排骨 | 25-30 分钟 |
| 蛋羹 | 8-12 分钟 |
| 包子、馒头 | 12-20 分钟 |
| 米饭 | 20-30 分钟 |
| 红薯 | 30-40 分钟 |
| 鸡(半只) | 25-30 分钟 |
| 大闸蟹 | 12-15 分钟 |

### 关键细节

1. **必须水开上锅**:否则水汽滴在食材上
2. **留间距**:让蒸汽流通
3. **盖子不能漏气**:用湿布堵住缝隙
4. **防滴水**:盘子上盖盘或铺葱姜
5. **嫩蒸**:时间宁短勿长
6. **回温**:`先大火烧开→再转中火` 让食材均匀受热

### 适合

- **清蒸鱼**(鲈鱼、鳜鱼、多宝鱼)
- **蛋羹**(嫩滑)
- **包子、馒头**(发面食品)
- **蒸排骨**(广东豉汁排骨)
- **扣肉**(梅菜扣肉)

---

## 六、炖(Braise/Stew)

> **核心**:小火 + 长时间 + 微沸

### 类型

| 类型 | 汤量 | 时间 |
|---|---|---|
| **清炖** | 多(没过食材) | 2-3 小时 |
| **煲** | 多 | 1-3 小时 |
| **焖**(盖紧盖小火) | 少 | 30-60 分钟 |

### 通用流程

```
食材焯水(或煎) → 入锅 →
→ 加热水(或高汤) → 加调料 →
→ 大火烧开 → 转小火 → 微沸 → 时间到
```

### 关键细节

1. **冷水下锅**:肉类先冷水下锅焯水
2. **一次加足水**:中途加水会降温
3. **小火微沸**:大沸腾肉会柴
4. **撇沫**:保持汤清
5. **调味**:
   - 一次到位:老火汤
   - 分次:红烧、酱焖
6. **盐**:出锅前 30-60 分钟
7. **香料**:八角、桂皮、香叶、陈皮
8. **糖色**(可选):红烧前炒糖色,色泽更红亮

### 适合

- **老火汤**:排骨莲藕汤、鸡汤
- **红烧**:红烧肉、红烧排骨
- **黄焖**:黄焖鸡
- **酱焖**:酱焖牛腩

---

## 七、焖(Braise)

> 比炖用汤少,介于红烧和干烧之间。

- **典型**:黄焖鸡、焖面、焖饭
- **关键**:汤汁收至将干时,盖盖焖入味

---

## 八、烧(Braise with Sauce)

> 与红烧接近,但更讲究"汁"的浓度。

### 类型

| 类型 | 特点 | 典型 |
|---|---|---|
| **红烧** | 老抽上色、糖增亮 | 红烧肉 |
| **白烧** | 不上色,汤白 | 白烧鱼 |
| **干烧** | 收干汤汁 | 干烧鱼 |
| **葱烧** | 大葱段 | 葱烧海参 |

### 红烧三要素

1. **上色**:糖色或老抽
2. **调味**:酱油 + 糖 + 酒
3. **收汁**:中火收到浓稠挂勺

---

## 九、烩、焗、烤

### 烩
- **方法**:食材入汤调味,芡汁包裹
- **典型**:烩面、烩饭、烩豆腐
- **关键**:勾芡(湿淀粉),汤汁浓稠

### 焗
- **方法**:利用热气把食材焖熟
- **典型**:盐焗鸡、焗海鲜
- **关键**:密封环境

### 烤
- **方法**:干热空气 + 高温(180-220℃)
- **典型**:烤鸭、烤鱼、烤箱菜
- **关键**:美拉德反应(无水高温)

---

## 十、凉拌(Cold Dish)

> **核心**:煮熟食材 + 调味 + 凉食

### 类型

| 类型 | 处理 |
|---|---|
| **生拌** | 洗净切好直接拌(黄瓜、生菜) |
| **熟拌** | 食材焯水或煮熟后拌 |
| **炝拌** | 食材煮熟,浇热油 + 调料 |

### 通用流程

```
食材准备(切/焯/煮) → 沥干 → 调酱汁 → 拌匀 → 装盘
```

### 万能凉拌汁(4:3:2:1)

```
4 醋 + 3 酱油 + 2 糖 + 1 辣椒油(芝麻酱)
+ 蒜末、姜末、香菜、葱花
+ 少许芝麻香油
```

### 关键细节

1. **食材沥干**:水多=味淡
2. **过冰水**:蔬菜更脆(白灼芥蓝)
3. **现拌现吃**:久放出水
4. **杀菌注意**:肉类/海鲜必须熟

### 适合

- **凉拌黄瓜**(刀拍黄瓜)
- **凉拌木耳**
- **凉拌牛肉**
- **凉拌鸡丝**
- **凉拌海蜇**
- **沙拉**

## 十一、特殊技法

### 焯水(Blanching)

**目的**:去腥、去血水、去草酸、保持色泽、定型

**分类**
| 方式 | 适用 |
|---|---|
| **冷水下锅** | 肉类(排骨、整鸡) |
| **沸水下锅** | 蔬菜、海鲜 |
| **加料焯** | 蔬菜(加油保色、加盐入底味) |

**关键**
- 蔬菜时间短(30 秒-2 分钟)
- 肉类煮开撇沫即可
- 焯后冲冷水(蔬菜更脆、肉类定型)

### 飞水、过油、拉油
- **飞水**:同焯水,粤菜说法
- **过油 / 拉油**:肉用油滑熟(嫩)

### 挂糊、上浆、勾芡

| 名称 | 做法 | 作用 | 典型 |
|---|---|---|---|
| **上浆** | 肉丝/片 + 蛋清 + 淀粉 + 油 | 嫩 | 滑炒肉丝 |
| **挂糊** | 整块食材 + 蛋糊/水粉糊 | 脆 | 炸里脊、糖醋鱼 |
| **勾芡** | 湿淀粉淋入汤汁 | 浓稠 | 红烧、烩菜 |

## 十二、烹饪法的现代变体

### 健康版改良

| 传统 | 健康改良 |
|---|---|
| 油炸 | 空气炸锅(180-200℃)、烤箱 |
| 红烧(重油重糖) | 减糖减油,加番茄增味 |
| 重盐 | 减盐 + 提鲜(蘑菇、番茄) |
| 长时间炖 | 高压锅(快 3-5 倍) |

### 工具加持

- **电压力锅**:炖肉 30-40 分钟替代 2 小时
- **空气炸锅**:无油或少油"炸"
- **蒸烤箱**:一机多用
- **料理机**:切碎、绞肉、磨酱

## 十三、烹饪法决策树

```
问:这道菜想吃什么口感?
├─ 脆嫩 → 爆炒(大火快炒)
├─ 软烂 → 炖(小火慢炖)
├─ 焦香 → 煎/烤(干热)
├─ 原味 → 蒸/白灼(蒸汽/热水)
├─ 浓味 → 红烧/酱焖(汤汁包裹)
├─ 清爽 → 凉拌(无油或冷食)
└─ 香酥 → 炸(高温油)
```

---

## 十四、组合烹饪(高级)

许多菜是**多种烹饪法的组合**:
- **红烧肉**:煎+焖+收汁
- **回锅肉**:煮+煎+炒
- **烤鸭**:腌+烫+晾+烤
- **糖醋鱼**:炸+烧
- **佛跳墙**:每个食材预处理 + 炖
