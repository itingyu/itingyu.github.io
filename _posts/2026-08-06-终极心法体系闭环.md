## 一、4 层底层机制(再精读)

### 1.1 第 1 层:微观结构

```
- 集合竞价(9:15-9:25 假象 + 真相)
- 订单簿(大单信号)
- 涨跌停(±10%)
- T+1(锁定 1 天)
```

**核心**:看懂市场怎么"瞬时"博弈

### 1.2 第 2 层:资金循环

```
- 央行(降准 / 互换便利 / 回购再贷款)
- 北向(外资风向标)
- 融资(杠杆)
- ETF(长期配置)
- 散户开户(情绪温度)
```

**核心**:看懂钱从哪来、到哪去

### 1.3 第 3 层:监管博弈

```
- 央行 / 证监会 / 金监局(三会)
- 政策定调
- 救市工具箱
- 国家队(中央汇金)
```

**核心**:看懂政策怎么"导演"

### 1.4 第 4 层:认知偏差

```
- 锚定 / 损失厌恶 / 羊群 / 处置 / 沉没
- 主力利用 = 割韭菜
- 散户修复 = 风控
```

**核心**:看懂"自己"怎么被利用

## 二、体系闭环的 5 大环节

### 2.1 环节 1:宏观定仓位

```
输入:PMI / CPI / M2 / 社融
输出:30-70% 仓位
- PMI > 50 + CPI < 3 = 70% 仓位
- PMI < 50 + CPI > 3 = 30% 仓位
- 其他 = 50% 仓位
```

### 2.2 环节 2:行业定方向

```
输入:行业景气度 / 周期阶段 / 政策
输出:行业选择
- 强行业 + 高景气 = 重点
- 弱行业 + 低景气 = 回避
- 周期股 = 复苏期买,高峰卖
```

### 2.3 环节 3:财报定标的

```
输入:ROE / 增速 / 现金流 / 护城河
输出:候选标的
- ROE > 15% 持续 3 年
- 增速 > 10%
- 经营现金流 > 净利润
- 护城河 4 种类型至少 1 种
```

### 2.4 环节 4:估值定价格

```
输入:PE / PB / PEG / DCF
输出:买卖价格
- PE < 15 = 便宜
- PEG < 1 = 便宜
- DCF > 市值 = 便宜
```

### 2.5 环节 5:心理定纪律

```
输入:7 大认知陷阱
输出:5 大铁律
- 锚定 → 不看买入价
- 损失厌恶 → 预设止损
- 羊群 → 独立思考
- 处置 → 统一纪律
- 沉没 → 认错比坚持重要
```

→ 结果:10 月顶部,后续调整
