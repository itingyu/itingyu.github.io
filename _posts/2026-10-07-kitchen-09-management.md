# 09 · 厨房管理与效率

> 会做菜 ≠ 会生活。本章讲怎么让做饭这件事变得轻松、有条理、不痛苦。

---

## 一、备餐流程(单人 30 分钟出一餐)

### 时间分配原则

**多线程并行**:洗菜+煮饭同时进行;切肉+焯水同时进行

### 标准流程(2 菜 1 汤)

```
T-30 分钟
├─ 淘米煮饭(电饭锅自动)
├─ 焯水(可同时进行) → 切配食材
└─ 处理肉类(腌制)

T-15 分钟
├─ 切配蔬菜
├─ 调酱汁(把调料提前在小碗里混好)
└─ 准备葱姜蒜末

T-5 分钟
├─ 起锅烧油
├─ 第一道菜(简单的先做,荤菜后做)
└─ 同时做汤

T-0 上桌
```

### 顺序原则

1. **先荤后素**(荤菜味重,先做完不串味)
2. **先煮后炒**(煮的耗时长,先开始)
3. **先凉后热**(凉菜可提前做)
4. **一道菜做完再起油锅**(避免串味)
5. **汤最先做**:炖汤耗时

---

## 二、预处理(周末备餐)

> **把一周的"苦力活"集中到一天**

### 周日备餐清单(2 小时备一周)

| 食材 | 处理 | 保存 |
|---|---|---|
| **肉类** | 切丝/片/丁 + 腌好 | 保鲜袋分装冷冻 |
| **葱姜蒜** | 切末/切片 | 冷藏 1 周 |
| **番茄** | 去皮切块 + 炒成酱 | 冷冻 1 月 |
| **高汤** | 一锅大骨汤 | 冷藏 3 天/冷冻 1 月 |
| **调味料** | 一次配齐耗油、生抽等 | 厨房固定位 |
| **米饭** | 一次煮一大锅 | 分装冷冻,微波复热 |
| **卤肉** | 一锅卤鸡腿/牛腱 | 冷藏 5 天 |

### 备餐工具

- **保鲜袋**(各种尺寸)
- **密封盒**(玻璃更健康)
- **标签 + 马克笔**(写日期 + 内容)
- **真空封装机**(可选)

## 三、冰箱管理

### 冰箱分区

```
┌─────────────────────────────┐
│  冷藏室                       │
│  ┌─────────────────────┐    │
│  │ 上层(温度最高)        │    │
│  │ → 剩菜、调味品、饮料   │    │
│  ├─────────────────────┤    │
│  │ 中层(常用)            │    │
│  │ → 蛋、奶、熟食         │    │
│  ├─────────────────────┤    │
│  │ 下层(温度最低)        │    │
│  │ → 生肉、海鲜           │    │
│  └─────────────────────┘    │
│  抽屉:蔬菜(独立空间,控湿度) │
└─────────────────────────────┘

┌─────────────────────────────┐
│  冷冻室                       │
│  -18℃                       │
│  生肉/海鲜分装               │
│  备餐分装                     │
│  冷冻蔬菜                     │
│  冰块                         │
└─────────────────────────────┘
```

### 冰箱 7 大原则

1. **生熟分开**:熟食上,生食下
2. **密封保存**:防止串味和细菌
3. **分装冷冻**:按一次用量分
4. **先进先出**:新买的放后面
5. **定期清理**:每周检查,过期丢弃
6. **不要塞满**:留冷气流通空间
7. **温度设置**:冷藏 0-4℃,冷冻 -18℃

## 四、厨房工具的最低配置(实用主义)

### 必备(8 件)

| 工具 | 用途 | 推荐预算 |
|---|---|---|
| 菜刀 + 砧板 | 切配 | 100-300 |
| 不粘炒锅(30cm) | 万能 | 150-400 |
| 汤锅(24cm) | 煮汤煮面 | 100-200 |
| 电饭煲 | 煮饭 | 200-1000 |
| 蒸锅(可叠加) | 蒸菜 | 100-200 |
| 锅铲 + 漏勺 + 汤勺 | 操作 | 50 |
| 厨房电子秤 | 调料精确 | 50-100 |
| 计时器 | 火候 | 30 |

### 推荐(进阶)

- **电压力锅**:炖肉神器(节省 60% 时间)
- **空气炸锅**:少油"炸"食品
- **烤箱**:烘烤、烤箱菜
- **料理机**:切碎、绞肉
- **微波炉**:解冻、热饭
- **电磁炉**:辅助热源(冬天桌上煮)

### 不建议新手买

- ✗ 铸铁锅(重,需养护)
- ✗ 各种小家电(占地方不常用)
- ✗ 整套刀具(用不到)
- ✗ 高级铜锅(不实用)

## 五、调料的"黄金布局"

### 灶台区(伸手可及)

- 盐、糖、生抽、老抽、醋、料酒、蚝油、食用油

### 操作台(常用)

- 鸡精/味精、豆瓣酱/甜面酱、芝麻油
- 葱姜蒜(小碗装)

### 调料柜(备用)

- 八角、桂皮、香叶、花椒、干辣椒
- 各种酱料(沙茶、咖喱、番茄酱)

### 冷藏(必冷藏)

- 蚝油(开封后)、黄豆酱、番茄酱(开封后)
- 各种新鲜香草

## 六、清洁与维护

### 厨房清洁的"333 法则"

- **每天**:台面、灶台、水池(饭后 5 分钟)
- **每周**:冰箱、地板、橱柜
- **每月**:油烟机、油壶、调料瓶

### 锅具保养

| 锅 | 保养 |
|---|---|
| **铁锅** | 用完洗净烧干 + 抹油(防锈养锅) |
| **不粘锅** | 不用钢丝球(划伤涂层),中小火 |
| **砂锅** | 用完洗净晾干,不要冷热交替(防裂) |
| **不锈钢** | 用白醋除水垢,柠檬去黑渍 |

### 刀具保养

- 用完立即擦干
- 每周磨刀 1-2 次
- 磁吸刀架 or 刀座收纳(避免碰伤)

## 七、效率技巧(做饭省时 50%)

### 1. 一锅出

- **电饭锅焖饭**:饭上蒸菜(红薯、芋头、排骨)
- **炖锅**:主菜 + 配菜一起炖
- **高压锅**:30 分钟排骨

### 2. 提前处理

- 周末备餐(见上)
- 当天腌肉(边煮饭边腌)
- 调料预混(碗汁)

### 3. 善用半成品

- **现成饺子皮**:包饺子
- **超市肉末**:省绞肉时间
- **净菜**(超市预处理蔬菜):省洗切时间
- **罐头番茄**:比鲜番茄稳定

### 4. 并行操作

- **煮饭 + 切菜**(同时)
- **焯水 + 切配**(同时)
- **炖菜 + 炒菜**(两个灶眼)

### 5. 减少收拾

- **所有材料分类装小碗**(切完直接下锅)
- **边做边擦台面**
- **碗盘用完立即洗**(避免堆积)

## 九、健康烹饪的 6 条原则

1. **少油**:能不油炸就不油炸,用空气炸锅
2. **少盐**:酱油减半,加醋、葱姜蒜提味
3. **少糖**:减糖,加番茄自然酸
4. **多蔬菜**:每餐 200g 以上
5. **粗细搭配**:白米 + 糙米/杂粮米
6. **多样化**:每周 25 种以上食材

### 减油减盐技巧

- 用不粘锅少油煎
- 用柠檬汁代替部分盐
- 用葱姜蒜爆香增加风味
- 用天然香料(花椒、八角)
- 用低钠酱油

## 十、厨房安全

### 防火

- **油锅起火**:盖锅盖(不要泼水)
- **燃气泄漏**:关阀、开窗、不动电器
- **电线老化**:定期检查

### 防烫

- 长袖、防烫手套
- 锅柄朝内(防撞翻)
- 微波加热小心"过热液"(过 30 秒再开)

### 防切伤

- 刀钝比刀快更危险
- 菜板防滑垫
- 食材完全擦干再切

### 防食物中毒

- **生熟分开**(刀、砧板、容器)
- **充分加热**(海鲜、肉类、蛋)
- **剩饭剩菜**:2 小时内冷藏
- **隔夜剩饭**:充分加热(中心 75℃+)
- **过期的食材**:立即丢弃

## 十一、做饭的"心态"

> 做饭不该是负担,而是**照顾自己和他人的方式**。

### 降低焦虑的 5 个方法

1. **不追求完美**:家常菜不是米其林
2. **接受"凑合"**:今天做不好明天再来
3. **失败记录**:每次失败记一条,下次避免
4. **学会取舍**:周末做大菜,工作日吃简单的
5. **把它当乐趣**:听音乐、追剧,顺便做饭

### 5 条饮食哲学

1. **饭吃七分饱**:留有余地
2. **清淡为上**:不是不能吃辣,不要顿顿重口味
3. **应季而食**:自然规律
4. **不时不食**:不反季节(反季蔬果口感差)
5. **多样饮食**:不偏食

## 十二、工具收纳

### 厨房收纳原则

1. **垂直收纳**(挂、架):释放台面
2. **就近原则**:刀在灶台旁、调料在灶台旁
3. **可视化**:常用在外,不常用在里
4. **分区**:调味区、清洁区、烹饪区、储存区

### 空间魔法

- **磁吸刀架**:墙上
- **挂钩**:挂锅铲、漏勺
- **挂篮**:装水果
- **置物架**:立体收纳
- **密封盒**:统一外观
- **标签**:贴日期

## 十三、从"会做饭"到"享受做饭"

### 进阶路径

1. **熟练 5 道家常菜**(家人爱吃)
2. **掌握基础调味**(咸鲜、糖醋、红烧、麻辣)
3. **理解食材**(识货、识季)
4. **学一道地方菜**(川、粤、淮扬选一个)
5. **有自己的招牌菜**(5-10 道拿手)
6. **尝试创新**(融合菜、自创)
7. **分享给朋友**(成就感)

### 推荐学习资源

- **App**:下厨房、豆果美食
- **视频**:王刚(硬核川菜)、老饭骨(国宴)、美食作家王刚
- **书**:
  - 《食物与厨艺》哈罗德·麦基
  - 《厨房里的哲学家》
  - 《中国烹饪概论》
  - 《川菜》(扶霞)
- **YouTube/B 站**:基础原理 + 实操

> **会做菜的标志:5 道拿手菜 + 灵活运用火候 + 敢创新不重复。**
