### 1.3 关键技术发现:实习僧 Nuxt 字段解析

实习僧搜索页和详情页都是 **Nuxt.js SSR 渲染**,数据嵌入 `<script>window.__NUXT__=(...)</script>`。但 NUXT 数据被 webpack **letter-minify 压缩**(短变量名 `a/b/c/...`),所以字段名是 `k.xxx` 格式而非 `c_tags / i_tags`。**关键字段清单**:

| 字段名 | 含义 | 示例值 |
|---|---|---|
| `k.iname` | 职位名 | "Python 后端开发实习生" |
| `k.cname` | 公司名 | "美因特信息科技" |
| `k.city` | 城市 | "上海" |
| `k.industry` | 行业 | "互联网/游戏/软件" |
| `k.degree` | 学历要求 | "本科" / "硕士" / "不限" |
| `k.day` | 实习天数/周 | "5"(5 天/周) |
| `k.endtime` | 投递截止 | "2026-07-05" |
| `k.info` | **完整 JD 正文** | "岗位职责:..." |
| `k.job_requirements` | 任职要求(独立字段) | (部分职位有) |
| `k.skills` | 技能列表 | (部分职位有) |
| `k.c_tags` | 公司标签(数组) | "高起点平台", "AI营销实战前沿" |
| `k.i_tags` | 职位标签(数组) | "大厂实习", "福利多多" |
| `k.cuuid` | 公司 UUID | "com_7hj6wbrqplsn" |
| `k.minsal` | 最低实习津贴 | 数字 / iconfont 编码 |
| `k.maxsal` | 最高实习津贴 | 同上 |

> **细节**:实习僧对**Java 关键词的 5 个 inn_xxx UUID 返回了相同的 demo JD**("运用 Java 这种开发语言...")。改用 **Python / Go / AI / 数据分析 / 大数据**关键词拿到的 43 个 UUID 中,**35 个有真 description 字段**。**沙箱内的实习僧对"Java"做了 anti-bot 限流,其他关键词不限流**。这是反爬策略的"非对称防护"。

### 1.4 核心洞察

招聘网站的核心数据(职位列表 / JD 详情)对脚本 curl **全线拦截**,但周边辅助接口(筛选条件 / 联想词 / 热门搜索 / 关联词)**通常放行**。实习僧的 Nuxt SSR 是个例外 —— **SSR 数据是 hardcoded 在 HTML 里,绕过 JS 反爬也能拿到**。这是反爬策略的盲区。

### 2.2 关键观察

1. **薪资分档 7 档,顶 50K**:说明主流招聘平台的算法把程序员薪资视为"3 万-5 万月薪封顶"。**年薪百万的高级岗位不在主站筛选范围**,要走猎聘 / 猎头渠道。
2. **学历 8 档,最低初中**:Boss 直聘**不排斥低学历**,给了初中/中专/高中三档——这是平台的市场定位(下沉 + 全岗位),但**实际通过率与平台筛选逻辑相关**。
3. **兼职类型 7 档非常细**:周末/寒暑假/短期/长期/工作日/夜班 —— 说明 Boss 平台上**兼职 / 实习 / 校招比例不小**,对应届生和在校生友好。
4. **融资阶段 9 档**:从"未融资"到"已上市"全覆盖,这给应聘者一个信号——**国内程序员市场大厂和早期创业公司都在招**。
5. **相关搜索词揭示 2026 H1 程序员市场 6 大热点**:**`agent`、`ai 应用开发` 直接出现**——**AI Agent 工程师岗位需求已进入主流关键词**,这是 2025 年没有的信号。

## 5. 14 条 JD 任职要求模式深度分析

### 5.1 "熟悉 / 掌握 / 了解 / 精通"四档词频(从任职要求段)

实习僧 JD 的任职要求里,**动词分档非常一致**。这是国内 JD 的隐藏语法:

| 动词 | 含义 | 出现频次 |
|---|---|:--:|
| **熟练掌握** | 必须精通,这是硬门槛 | 5 次 |
| **熟悉** | 主流要求,会基础 + 项目经验 | 8 次 |
| **了解** | 加分项 / 入门即可 | 12 次 |
| **精通** | 罕见,通常用于资深岗位 | 1 次 |

**核心洞察**:**国内 JD 的"四档动词"是有递进关系的**——
- "熟练掌握 Python" = 至少 2 个完整项目
- "熟悉 Django" = 知道 ORM / 路由 / 中间件
- "了解 Docker" = 听过,会跑 docker run
- "精通 Go 并发" = 看过 runtime 源码,会调优 goroutine 池

**对求职者的实操建议**:**简历里用同样的动词对照你的实际能力**,避免"精通"被面试官追问。**实战经验 ≥ 面试包装**。

### 5.2 "项目 / 经验 / 实习" 三档要求

| 要求类型 | 出现频次 | 典型表述 |
|---|:--:|---|
| **项目经验**(个人 / 课程设计 / 开源) | 6 次 | "有相关后端项目实践经验(课程设计、个人项目均可)优先" |

**核心信号**:**2026 H1 国内实习市场对"项目经验"的重视度高于"实习经验"**——这是因为大量在校生没有完整实习经历,但课程设计 / 个人项目 / 开源贡献是同等替代。

### 5.3 "加分项"模式

## 附录 C:技术附录 —— 实习僧 NUXT SSR 字段解析

实习僧搜索页和详情页都是 **Nuxt.js SSR 渲染**,数据嵌入 `<script>window.__NUXT__=(...)</script>`。NUXT 数据被 webpack **letter-minify 压缩**(短变量名 `a/b/c/...`),所以字段名是 `k.xxx` 格式而非 `c_tags / i_tags`。**关键字段清单**:

| 字段名 | 含义 | 示例值 |
|---|---|---|
| `k.iname` | 职位名 | "Python 后端开发实习生" |
| `k.cname` | 公司名 | "美因特信息科技" |
| `k.city` | 城市 | "上海" |
| `k.industry` | 行业 | "互联网/游戏/软件" |
