> **一句话**:**板块轮动 = 资金在不同板块之间的迁移**。**4 大底层规律 + 10 大真实剧本 + 8 步实操**。**看懂轮动 = 看懂 A 股节奏**。

---

## 一、4 大底层规律

### 1.1 规律 1:政策驱动轮动

```
政策出台 → 相关板块启动 → 资金跟进 → 板块轮动
```

**案例**:
- 924 行情:央行+证监会+金监局同台 → 金融 / 地产 / 消费启动
- 2024 新国九条:ST / 微盘股跌,红利 / 中字头涨
- 2024-2025 设备更新 + 消费品以旧换新 → 家电 / 汽车 / 工程机械

### 1.2 规律 2:产业周期轮动

```
产业周期:导入 → 成长 → 成熟 → 衰退
        ↓      ↓      ↓      ↓
      主题投资  业绩投资  价值投资  防御
```

**案例**:
- 2018-2022 新能源:导入(2018) → 成长(2019-2021) → 成熟(2022)
- 2024-2025 AI 算力:导入 → 成长初期

### 1.3 规律 3:估值修复轮动

```
低估值板块(银行 / 地产 / 钢铁 / 煤炭)
→ 政策催化 / 业绩反转
→ 估值修复
→ 戴维斯双击
```

**真实案例**:
- 2024-2025 银行股:**PB 0.6-0.7 + 利率下行 + 政策支持** → +80%+
- 2024-2025 红利板块:股息率 5%+ → 持续上涨

### 1.4 规律 4:风险偏好轮动

```
经济差 → 防御板块(食品饮料 / 医药 / 公用事业)
经济好 → 周期板块(有色 / 化工 / 钢铁)
政策刺激 → 金融 / 地产
```

**实战框架**:
| 经济阶段 | 板块配置 |
|---|---|
| 衰退 | 防御 + 红利 |
| 复苏 | 金融 + 周期 |
| 过热 | 周期 + 资源 |
| 滞涨 | 防御 + 现金 |

## 二、A 股 10 大真实剧本(2020-2026 复盘)

### 2.1 剧本 1:政策反转行情

- **特征**:政策重大转向 + 指数快速反弹
- **代表**:2024-09-24 924 行情(沪指 +4.15%)
- **持续**:3-6 个月

### 2.2 剧本 2:戴维斯双击(估值修复)

- **特征**:低估值 + 业绩反转 → PE 和 EPS 双升
- **代表**:2024-2025 银行股(+80%+)

### 2.3 剧本 3:景气驱动(产业周期)

- **特征**:行业景气度持续向上 + 龙头业绩爆发
- **代表**:2024 存储芯片 / 2024-2025 AI 算力

### 2.4 剧本 4:主题炒作

- **特征**:概念 + 短线资金 + 涨停板敢死队
- **代表**:2024 北化股份 17 连板(纯粹炒作)
- **注意**:多数散户亏损

### 2.5 剧本 5:白马崩盘

- **特征**:核心资产高估 + 业绩不及预期
- **代表**:2020-2021 抱团股崩盘(2020 白马 + 2021 新能源)

### 2.6 剧本 6:杠杆出清

- **特征**:杠杆 / 衍生品踩踏
- **代表**:2024-01-22 雪球敲入

### 2.7 剧本 7:监管冲击

- **特征**:退市 / 监管政策变化
- **代表**:2024 退市 52 家(ST / 微盘股暴跌)

### 2.8 剧本 8:外部冲击

- **特征**:关税 / 地缘 / 海外市场波动
- **代表**:2025-04-07 关税冲击

### 2.9 剧本 9:新股爆炒

- **特征**:新股 / 次新股短期暴涨
- **代表**:多见于牛市中期

### 2.10 剧本 10:慢牛 / 慢熊

- **特征**:指数长期横盘 / 慢涨 / 慢跌
- **代表**:2024-2025 银行股慢牛 / 2018 慢熊

## 三、实战拆解:2026-07-15 医药 vs 半导体

### 3.1 当时情况

| 板块 | 走势 | 原因 |
|---|---|---|
| **医药** | 短期调整 | 集采 / 政策 |
| **半导体** | 持续上涨 | 国产替代 + AI 算力 + 周期反转 |

### 3.2 操作策略

```
医药:基本面没变 → 持有 / 分批加仓
半导体:景气度向上 + 估值合理 → 持有
```

### 3.3 教训

- 短期波动 ≠ 长期趋势
- 政策冲击是"加仓机会"还是"减仓信号"?**看基本面**
- 行业景气度 > 个股技术面

## 四、板块轮动实操 8 步法

```
Step 1  确定经济周期(衰退/复苏/过热/滞涨)
Step 2  找出政策催化(政策 / 改革 / 产业规划)
Step 3  行业 5 步法(详见精华 08)
Step 4  5 大景气度指标(详见精华 09)
Step 5  PB-ROE 矩阵(低估值 + 高 ROE = 戴维斯双击)
Step 6  龙头股信号(龙头提前启动)
Step 7  情绪温度计(绝望 → 狂热)
Step 8  风险控制(止损 -8% / 仓位 ≤ 70%)
```

### 实战案例:2024 银行股(完整 8 步)

| Step | 分析 |
|---|---|
| 1. 经济周期 | 衰退末期 → 复苏初期 |
| 2. 政策催化 | 央行降准 + 利率下行 + 央企支持 |
| 3. 行业 5 步法 | 成熟期 + 牌照壁垒 + CR3 集中 |
| 4. 5 大景气度 | 利率 ↓ / 估值 ↓ / 政策 ↑ / 业绩稳 |
| 5. PB-ROE 矩阵 | **PB 0.6-0.7 + ROE 10% = 戴维斯双击** ⭐ |
| 6. 龙头信号 | 工行 / 农行 / 中行 提前启动 |
| 7. 情绪温度 | 绝望期 → 怀疑期(分批加仓) |
| 8. 风险控制 | 仓位 30% → 50% → 60%(金字塔) |

**结果**:2024-2025 银行股 +80%+

> 💬 **"板块轮动 = 政策 × 估值 × 景气 × 情绪"的 4 维交叉**。**8 步法 = 把'轮动'变成'可执行'**。

## 五、轮动 vs 选股的关系

```
轮动 = 选对方向(配什么板块)
选股 = 选对个股(板块内的龙头)

→ 两者都重要
→ 轮动错了,再好的个股也白搭
→ 选股错了,再好的板块也白搭
```

**案例**:
- 2024 选错板块(买 ST) → 即使选对个股(某 ST 反包)也赚不多
- 2024-2025 选对板块(银行) → 即使选错个股(某城商行)也能赚

> 💬 **"板块轮动是'70% 收益的来源',选股是'20%',择时是'10%'。"**
