# 命名系统（3）：医药健康——把药理写进名字

医药行业的命名有个别的行业没有的特点：**名字本身就是一张处方信息**。

医生看到 `-olol` 就知道是 β 受体阻滞剂，药师看到 `-mab` 就知道是单抗，医保系统看到 `C10AA05` 就知道该走哪档支付。这种把分类学直接编码进名字的做法，全世界只有医药做得最彻底。

## 一、INN：一套人为设计的世界语

国际非专利药名（INN）由 WHO 在 1950 年代启动，目标是给每个活性成分一个全球通用的名字。它的结构是：

```
前缀（区分同词干药物） + 词干（药理分类） + 盐/酯后缀
```

以 `atorvastatin`（阿托伐他汀）为例：`atorva-` 是区分用的前缀，`-statin` 是词干，指明 HMG-CoA 还原酶抑制剂这一类。

### 常用词干表

| 词干 | 药理类别 | 代表药 | 中文词干 |
|:--|:--|:--|:--|
| -olol | β 受体阻滞剂 | propranolol | 洛尔 |
| -pril | ACE 抑制剂 | enalapril | 普利 |
| -sartan | 血管紧张素 II 受体拮抗剂 | losartan | 沙坦 |
| -statin | HMG-CoA 还原酶抑制剂 | atorvastatin | 他汀 |
| -prazole | 质子泵抑制剂 | omeprazole | 拉唑 |
| -dipine | 钙通道阻滞剂 | amlodipine | 地平 |
| -azepam | 苯二氮䓬类 | diazepam | 西泮 |
| -ciclovir | 抗病毒核苷类似物 | acyclovir | 洛韦 |
| -xaban | 凝血因子 Xa 抑制剂 | rivaroxaban | 沙班 |
| -gatran | 凝血酶抑制剂 | dabigatran | 加群 |
| -gliptin | DPP-4 抑制剂 | sitagliptin | 列汀 |
| -glutide | GLP-1 受体激动剂 | semaglutide | 鲁肽 |
| -flozin | SGLT2 抑制剂 | dapagliflozin | 列净 |
| -tinib | 酪氨酸激酶抑制剂 | imatinib | 替尼 |

单抗的 `-mab` 还有二级词干，标明来源：

| 词干 | 来源 |
|:--|:--|
| -momab | 鼠源 |
| -ximab | 嵌合 |
| -zumab | 人源化 |
| -limumab | 全人源 |

所以 `adalimumab`（阿达木单抗）从名字就能读出：全人源单抗。

### 规则里的硬约束

1. **词干不得注册为商标**，保证任何厂商都能用。
2. **词干资源有限**。新机制层出不穷，WHO 要不断造新词干，还要避免与已有词干混淆。
3. **中文译名同步映射**：`-statin` → 他汀，`-pril` → 普利，这套对应关系是约定俗成的，药典和医保目录都遵循。

## 二、ATC：五级分类树

ATC 是 WHO 的药物分类系统，按「解剖-治疗-药理-化学」五级展开：

```
C10AA05  atorvastatin
│ │  │ │ └─ 第五级：具体物质
│ │  │ └─── 第四级：化学亚组
│ │  └───── 第三级：药理亚组
│ └──────── 第二级：治疗亚组
└────────── 第一级：解剖主组（14 个）
```

逐级读出来就是：心血管系统（C）→ 血脂调节药（C10）→ 单方 HMG-CoA 还原酶抑制剂（C10A）→ 具体到阿托伐他汀（C10AA05）。

ATC 的几个特点：

- **一位字母 + 两位数字 + 一位字母 + 一位字母 + 两位数字**，固定 7 个字符
- 第一级只有 14 个字母（A、B、C、D、G、H、J、L、M、N、P、R、S、V），没有 E、F、I、K、O、Q、T、U、W、X、Y、Z
- 一个药可能对应多个 ATC 码（不同适应症）
- ATC 不等于治疗等价，做药物经济学研究时要配合 DDD（限定日剂量）

## 三、ICD：疾病分类的百年工程

ICD 的历史比 INN 长得多。1893 年国际统计学会通过 Bertillon 的死亡原因分类，1948 年 WHO 接手第六版，之后每十几年修订一次。

### 结构

ICD-10 的码是「字母 + 两位数字 + 小数 + 扩展」：

```
I21.0  急性前壁心肌梗死
```

ICD-11 改成了更灵活的后组配（postcoordination）：主干码（stem code）四字符，如 `1A00`，再用扩展码补充部位、严重程度、病因。这解决了 ICD-10 里「码不够用、只能塞进扩展位」的老问题。

### 中国实践

国内同时跑着好几套：

- **国家临床版**（ICD-10 国临版）
- **医保版**（ICD-10 医保版 2.0）
- **ICD-9-CM-3**（手术操作编码）
- **ICD-11**（试点推进中）

DRG/DIP 付费直接建立在 ICD + 手术操作编码之上。编码错一位，入组就变，钱就跟着变。所以医院的病案室是一个 IT 部门之外最像 IT 部门的地方——他们在做数据治理，只不过治理的对象是诊断名。

## 四、检验与变异：LOINC 与 HGVS

### LOINC

检验项目的标准编码，六段语义：

```
成分 : 属性 : 时间 : 样本 : 精度 : 方法
```

例：`2160-0` = Creatinine [Mass/volume] in Serum or Plasma。

六段拆开：肌酐 / 质量浓度 / 时点 / 血清或血浆 / 定量 / 未指定方法。同一项目换样本类型或方法，就是另一个 LOINC 码。

### HGVS

基因变异命名由人类基因组变异学会维护，前缀决定坐标系：

| 前缀 | 坐标系 |
|:--|:--|
| g. | 基因组 |
| c. | 编码 DNA |
| p. | 蛋白 |
| m. | 线粒体 |
| n. | 非编码 RNA |

例：`NM_000546.6:c.215C>G (p.Pro72Arg)`。

注意那个 `NM_000546.6`——**转录本版本号必须写**。同一个基因有多个转录本，不写版本，同一串 `c.` 坐标可能指向不同位置。这是临床报告里最常见的低级错误。

## 五、器械：UDI

医疗器械唯一标识（UDI）由两部分组成：

- **DI（器械标识）**：静态，标识型号规格
- **PI（生产标识）**：动态，含批号、序列号、有效期

发证机构主要有三家：GS1、HIBCC、ICCBBA。UDI 要上传到各国数据库（美国 GUDID、中国 UDI 数据库），实现「一物一码、全程追溯」。

## 六、中药：另一套逻辑

中药的命名不走 INN 那套，走的是**药典正名 + 炮制品名 + 地方名**三层：

- 正名：《中国药典》规定的法定名称，如「白芍」
- 炮制品：炒白芍、酒白芍
- 地方名/习用品：同一个名字在不同地区可能指不同植物

最惨痛的教训是「木通」。关木通（马兜铃科）和川木通（毛茛科）都叫木通，前者含马兜铃酸，长期服用导致肾衰竭。2003 年事件之后，药典取消了关木通的药用标准。

**同名异物在中药里不是小问题，是安全问题。** 这也是为什么药典要给每个药材配拉丁学名——拉丁名是最终裁决者。

## 七、这一行的启示

1. **词干系统是可以抄的**：如果一个行业有稳定的类别体系，把类别编进名字的后缀，能极大降低认知成本。
2. **词干会被耗尽**：设计时要预留扩展空间，允许二级词干。
3. **一旦命名和钱挂钩，编码质量就成了财务问题**：ICD 之于 DRG 就是例子。
4. **别名必须有权威表**：中药的地方名、基因的别名、药品的商品名，都要有一张官方同义词表兜底。
