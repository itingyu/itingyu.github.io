进阶技法

2026-10-07 · cooking · 厨房学 · 约 1 分钟 · 统计中…

从"会做菜"到"做得精"的分水岭。掌握这些,你的菜会上一个台阶。

从"会做菜"到"做得精"的分水岭。掌握这些,你的菜会上一个台阶。

一、上浆(Coating)

目的:用浆液包裹肉,锁住水分,让肉更嫩滑

适用

  • 滑炒的肉丝、肉片、肉丁
  • 滑溜的鱼片、虾仁

基础浆(蛋清浆)

原料 200g(肉丝/片/丁)
+ 盐 2g
+ 料酒 5ml
+ 蛋清 1 个
+ 干淀粉 10-15g
+ 油 10ml(封浆用,防粘连)

步骤

  1. 肉切好
  2. 加盐、料酒抓匀(入味 + 抓至发黏)
  3. 加蛋清抓匀
  4. 加干淀粉抓匀
  5. 最后加油拌匀
  6. 静置 15-30 分钟

全蛋浆

  • 蛋清+蛋黄(全蛋)
  • 适合:鱼片、虾仁(蛋黄色浅,做金黄色)

水淀粉浆(无蛋)

  • 肉 + 盐 + 料酒 + 淀粉 + 水
  • 适合:素菜、减肥餐

上浆的关键

  • 上浆前挤干肉(否则水多浆薄)
  • 抓至起胶(肉表面有黏性)
  • 油封:最后加油防粘、防脱浆
  • 下锅温度:三-四成油温(90-130℃),太低脱浆,太高结块

上浆失败的诊断

现象原因
脱浆油温太低、肉没挤干、没"封油"
浆过厚淀粉太多、没抓匀
口感糊油温太高、没滑散
肉老没腌、没封油、火太大

二、挂糊(Battering)

目的:在食材外裹糊,炸后外酥脆、内软嫩

类型对比

类型配方特点典型菜
全蛋糊蛋 + 面粉 + 水金黄酥炸茄盒、炸虾仁
蛋清糊(水粉糊)蛋清 + 淀粉 + 水浅色、脆锅包肉、糖醋鱼
脆糊面粉 + 淀粉 + 油 + 泡打粉极脆(膨松)炸蘑菇、炸海鲜
面包糠糊蛋液 + 面包糠酥脆金黄炸猪排、炸鸡
苏打浆蛋 + 面粉 + 小苏打松软软炸里脊

全蛋糊(万能)

鸡蛋 2 个 + 面粉 50g + 淀粉 30g + 水 30ml + 盐 2g + 油 10ml
  • 拌匀至无颗粒,挑起可拉丝
  • 静置 10 分钟让面粉吸胀

脆糊(膨松酥脆)

面粉 50g + 淀粉 50g + 水 80ml + 泡打粉 3g + 油 10ml
  • 关键:油最后加,炸时更脆
  • 现拌现用(泡打粉 10 分钟失效)

蛋清糊(用于 锅包肉、糖醋鱼)

蛋清 2 个 + 淀粉 80g + 水 30ml + 油 5ml

挂糊流程

食材处理(腌好/拍粉/拍水)
   ↓
裹糊(均匀挂满)
   ↓
静置 5-10 分钟
   ↓
下油锅(六成油温,150-170℃)
   ↓
定型 → 翻面 → 炸透
   ↓
捞出 → 控油
   ↓
(可选)复炸(高温 30 秒)

挂糊的关键

  • 食材要干:湿食材挂糊会"花脸"
  • 糊要均匀:不能有裸露点
  • 现挂现炸:挂完久放脱糊
  • 油温稳定:忽冷忽热影响脆度

三、勾芡(Thickening)

目的:用淀粉使汤汁浓稠,包裹味道

类型

方式做法适用
湿淀粉勾芡淀粉 + 水 = 湿淀粉(1:2-3) → 淋入汤中家常最常用
干淀粉撒干淀粉直接撒入汤类
二次勾芡分两次勾红烧、烩菜
明油勾芡勾芡后淋油出锅亮油

湿淀粉调制

干淀粉 10g + 冷水 20ml
    → 拌匀无颗粒

关键:必须冷水调开(热水直接下锅会结块)

勾芡时机

菜时机
炒菜出锅前 30 秒
汤起锅前 1 分钟
红烧中段(留汤再收)
烩菜出锅前

勾芡的三种浓度

  • 薄芡:汤汁可流动(汤)
  • 中芡:汤汁挂勺(红烧、烩)
  • 浓芡:汤汁完全包裹食材(糖醋)

关键

  • 边淋边搅:防结块
  • 分次少量:宁少勿多(稠了不可逆)
  • 关火前勾:防过熟
  • 淋油亮芡:出锅前淋明油(防黏连、增加光泽)

四、码味(Preliminary Seasoning)

概念:给食材"打底味",分多次加调料,比一次性腌更入味

三阶段码味

阶段 1(原料处理时):底味
  → 盐 + 料酒 + 姜片 + 葱段
  → 蔬菜:5-10 分钟
  → 肉:15-30 分钟

阶段 2(下锅时):增味
  → 酱油、蚝油、糖
  → 一次性主调

阶段 3(出锅前):补味
  → 醋(高温挥发)
  → 葱花、香菜(留香)
  → 鸡精(过高温鲜味丢)
  → 香油(关火加)

不同食材的码味

食材腌料时间
猪肉丝盐、料酒、生抽、淀粉、油15 分钟
牛肉片盐、料酒、嫩肉粉(小苏打)、油30 分钟
鸡丁盐、料酒、蛋清、淀粉、油15 分钟
鱼片盐、料酒、蛋清、淀粉、油10 分钟
虾仁盐、料酒、蛋清、淀粉、油10 分钟
鸡腿肉盐、料酒、姜片、生抽30 分钟-2 小时
整鸡盐抹表面、葱姜塞内4 小时-1 夜

五、熬糖色(Caramelization)

目的:糖经高温焦糖化,产生红褐色+焦香

方法一:油炒糖色(最快)

1. 锅烧热 → 下油(冷油)→ 加冰糖(中号锅 50-100g)
2. 小火慢慢加热
3. 糖融化(冒泡)→ 颜色由浅变深
4. 颜色判断:
   - 浅黄 → 香甜
   - 金黄 → 标准
   - 深琥珀(浅褐)→ **最佳糖色**(关火)
   - 深褐 → 微苦
   - 黑 → 失败
6. 立刻下食材翻炒上色(糖色会瞬间焦化)

方法二:水炒糖色(更易控)

1. 锅加水 + 糖(1:1)
2. 中火熬(不停搅)
3. 颜色变深 → 立刻下食材

关键

  • 小火慢熬(急火会焦)
  • 看颜色:琥珀色立刻关火(余温会继续)
  • 提前备好食材:糖色变深很快
  • 油量控制:油多易溅,糖多易焦

何时熬糖色

  • 红烧肉(红亮关键)
  • 卤水(老抽替代,但糖色更红亮)
  • 拔丝菜(糖醋、糖丝)
  • 糖色拌面(葱油拌面加糖色)

六、制高汤(Stock)

高汤 = 厨房的"鲜味基石"

1. 毛汤(基础白汤)

材料:猪骨 1kg + 鸡架 1 个 + 姜 50g + 葱 100g
      + 水 4L

步骤:
1. 骨头冷水下锅焯水
2. 捞出温水冲洗
3. 大锅加水 → 骨头下锅
4. 大火烧开 → 转小火
5. 撇沫(开盖 10 分钟)→ 加葱姜
6. 小火微沸 4-6 小时(中间不搅)
7. 关火前 10 分钟加盐(早加微起保鲜)
8. 过滤 → 冷却 → 冷藏/冷冻

2. 奶白汤

区别:大火烧开(沸腾),脂肪乳化 → 汤白
应用:鲫鱼豆腐汤、猪蹄黄豆汤
关键:必须保持沸腾

3. 清汤(更清澈)

材料:老母鸡 1 只 + 猪骨 500g + 干贝 50g
步骤:
1. 焯水
2. 加水 → 大火烧开
3. 小火微沸 4 小时
4. 过滤
5. 再加鸡腿肉末(吸附杂质) → 小火 1 小时
6. 再过滤 → 清汤

4. 素高汤(纯素)

材料:
- 干香菇 30g(泡发切)
- 海带 30g
- 玉米 1 根(切段)
- 黄豆 50g
- 胡萝卜 1 根
- 水 2L

步骤:
1. 所有材料加水
2. 大火烧开
3. 小火 2 小时
4. 过滤
5. 鲜味来自蘑菇的谷氨酸

5. 番茄高汤

  • 鱼骨 + 洋葱 + 胡萝卜 + 西红柿
  • 大火熬 1 小时(酸味让鱼骨快速出味)

6. 鸡精/浓汤宝的替代

自制替代
高汤冷冻鸡精
蘑菇水浓汤宝
干贝泡水浓缩海鲜汁

七、卤水(Braising Liquid)

卤水 = 香料 + 高汤 + 酱油 + 糖色
用过的卤水越用越香,叫"老卤"

基础卤水配方(可卤 2-3kg 食材)

主料

  • 高汤 2L(毛汤即可)
  • 水 1L

酱料

  • 生抽 100ml
  • 老抽 50ml(上色)
  • 冰糖 50g
  • 料酒 50ml
  • 盐 30g

香料(纱布袋包)

  • 八角 3 颗
  • 桂皮 1 小段(2cm)
  • 香叶 3 片
  • 草果 1 个(去籽,否则苦)
  • 花椒 20 粒
  • 干辣椒 5 个
  • 丁香 2 颗(少,多了苦)
  • 白芷 2 片
  • 小茴香 5g
  • 陈皮 1 小块

葱姜

  • 姜 50g(拍碎)
  • 葱 50g(打结)
  • 蒜 30g

步骤

1. 高汤烧开
2. 加酱料 + 糖(糖先化)
3. 加香料包 + 葱姜蒜
4. 大火烧开 → 转小火 30 分钟(出味)
5. 下食材
6. 根据食材调时间:
   - 鸡腿/翅:30-40 分钟
   - 排骨:40-60 分钟
   - 牛肉:60-90 分钟
   - 鸡蛋(提前煮熟剥壳):20-30 分钟
   - 豆制品:10-15 分钟
   - 海鲜:5-10 分钟
7. 关火 → 让食材泡在卤水里 1-4 小时(更入味)
8. 取出 → 沥干 → 切件

老卤的保养

  1. 过滤残渣(每次卤完)
  2. 烧开保存(每日烧开一次,或冷藏)
  3. 冷藏(2 周内用完)
  4. 冷冻(长期保存)
  5. 定期补味:每卤 3 次,补香料、酱料
  6. 撇油:老卤上层有脂肪(隔绝空气,保鲜),保留

卤水的种类

类型特点适合
红卤老抽上色(红)卤肉、卤蛋
白卤不上色卤鸡、卤海鲜
辣卤加干辣椒、花椒鸭脖、毛豆
酱卤加甜面酱北派(卤牛肉)

八、辣椒油与辣子油

自制辣椒油

材料:
- 干辣椒粉 50g
- 花椒粉 10g(可选)
- 白芝麻 20g
- 八角 2 颗,桂皮 1 小段
- 油 200ml

步骤:
1. 辣椒粉 + 白芝麻 + 花椒粉 → 碗中
2. 油 + 八角 + 桂皮 → 小火慢炸
3. 油温 180℃(微烟)→ 关火
4. 捞出八角桂皮
6. 油分 3 次淋入辣椒碗(防炸焦)
   - 第一次 1/3,搅匀
   - 第二次 1/3,搅匀
   - 第三次 1/3(油温下降,可全淋)
7. 冷却 → 装瓶 → 室温保存 3-6 月

关键:油温要够(激发香气),但不能太烫(烧焦)

九、葱油

材料:
- 小葱 200g(整条,或葱白)
- 油 100ml

步骤:
1. 葱洗净 → 沥干(防溅)
2. 锅烧热 → 油
3. 小火 → 葱下锅
4. 慢炸 5-10 分钟
5. 葱变深褐色 → 关火
6. 葱油装瓶,葱段捞出可配面

用途:葱油拌面、凉拌菜、葱油鸡

十、麻酱(芝麻酱)的"澥"

麻酱直接用会稠,需要"澥"开

澥法

1. 麻酱 30g 入碗
2. 加凉白开 10ml(分次)
3. 顺时针搅拌
4. 多次加水,每次搅匀再加
5. 直到顺滑(约 1:1 比例)

变体:
- 加香油澥(更香)
- 加花生酱(更香浓)
- 加腐乳汁(老北京味)
- 加醋(酸辣麻酱)

十一、制酱料

自制蒜蓉

蒜末 + 油(1:1) + 盐 + 糖 + 生抽
→ 浸泡 1 小时后用
用途:蒜蓉虾、蒜蓉扇贝

自制番茄酱

番茄去皮 → 切块
+ 洋葱碎 + 蒜末 + 番茄酱 + 醋 + 糖 + 盐
→ 小火熬 30-60 分钟
→ 浓稠即可
用途:番茄酱意面、蘸薯条

自制沙拉酱

蛋黄 1 个 + 油 100ml(分次)→ 蛋黄酱
+ 柠檬汁 + 盐 + 糖 + 芥末
→ 调匀

十二、肉类嫩化的"三大方法"

1. 物理嫩化

  • 刀背拍:断纤维(如拍牛肉)
  • 逆纤维切(关键!)
  • 戳针:用叉子或松肉锤戳孔

2. 化学嫩化

  • 盐腌:渗透压 + 钠离子打散蛋白网络
  • 碱腌:小苏打 / 碱水(pH 升高,松散蛋白) - 注意:用量控制(肉 500g + 碱 1-2g,过量发碱味)
  • 淀粉腌:淀粉填充纤维,锁水
  • 菠萝 / 猕猴桃腌:蛋白酶分解(果酸) - 注意:量过多会烂

3. 生物嫩化

  • 酸奶 / 醋腌:酸性蛋白酶嫩化
  • 木瓜 / 菠萝汁腌:同上(植物蛋白酶)

嫩肉粉(嫩肉粉 = 木瓜蛋白酶 + 淀粉 + 盐)

  • 用法:肉 500g + 嫩肉粉 3-5g
  • 时间:15-30 分钟
  • 注意:不宜过量(肉会散)

十三、去沫撇油(汤类)

浮沫(血沫)

  • 焯水时产生(蛋白质变性)
  • 必须撇(影响汤清度和口感)
  • 冷水下锅:血沫在冷水升温中逐渐析出(比沸水下锅多)
  • **撇浮工具:勺子/油撇子

浮油

  • 炖汤产生的脂肪
  • 汤用:撇掉(清淡)
  • 奶白汤:保留(乳化需要脂肪)
  • 保留做菜:捞出做油拌菜或炼荤油

十四、油温控制与判断

(详见 [05-火候掌控](05-火候掌控.md))

进阶点:

  • 红外温度枪(¥100):精准
  • 家用温度计(¥30):基础
  • 手心试温(经验)
  • 姜丝试温(常用)
  • 葱段试温(常用)

十五、面糊的"脆度决定因素"

因素影响
面粉比例多面粉 → 硬脆;多淀粉 → 轻脆
泡打粉加 → 膨松(脆但不硬)
油温高温 → 焦脆;低温 → 软脆
复炸是 → 极脆
糖加 → 易上色(微苦)
油量油多 → 脆

脆的"金字塔":脆糊 + 复炸 > 蛋清糊 + 复炸 > 蛋清糊 > 全蛋糊

十六、香料的"使用时机"

香料时机原因
整香料(八角、桂皮)长时间加热(卤、炖)慢慢出味
粉末香料(花椒粉、辣椒粉)出锅前高温丢香
葱姜蒜中段爆香激发香气
香草(香菜、薄荷、罗勒)装盘装饰为主
陈皮炖、卤提香 + 解腻
砂仁卤异香
五香粉红烧、卤复合香

十七、进阶的"分寸感"

香料多了怎么办

  • 加奶制品(奶汤、奶酪)化解
  • 加糖
  • 加酸(醋、番茄)

咸了怎么办

  • 加水稀释 + 加配菜(土豆吸汤)
  • 加糖、葱姜(煽盐)

酸了怎么办

  • 加糖
  • 加水稀释

苦了怎么办

  • 加糖
  • 加奶制品
  • 重做(基本不能救)

十八、留"锅气"与"锅香"

锅气

  • 大火快炒,出锅瞬间的香气
  • 形成条件:锅要够热、油要够热、炒的时间短

锅香

  • 食材在锅里留下的"焦香底"
  • 专业厨师:炒完一道菜留锅香再炒下一道(比如有缘的菜用同一锅)

十九、家厨 vs 餐厅的差异

维度家厨餐厅
火中火为主大火(火力大)
油少油多油(易操作)
调味适中重(味浓才能突出)
糊薄糊厚糊(脆)
盐适中多(咸度补"过量"残留)
速度不快极快(爆炒 1 分钟)
份量小份大份

家厨模仿餐厅:

  • 大火快炒(火力开最大)
  • 不放油(少油版本)
  • 调味稍重(咸度提 10-20%)

二十、推荐进阶菜谱

掌握这些技法后,挑战:

  1. 脆皮炸鸡(挂糊 + 复炸)
  2. 糖醋鱼(整鱼花刀 + 挂糊 + 浇糖醋汁)
  3. 红烧狮子头(肉馅调制 + 红烧)
  4. 狮子头(剁肉 + 上劲 + 炖)
  5. 卤鸡爪(卤水 + 老卤保养)
  6. 红烧排骨(收汁挂勺)
  7. 宫保鸡丁(汁:酸 + 辣 + 甜 + 咸)
  8. 葱烧海参(高汤 + 收汁)
  9. 佛跳墙(家庭简版)
