四、有益成分及保留方法(关键!)

A. 维生素

1. 维生素 C(水溶性,极易流失)

| 食物 | 含量 | 损失条件 | |---|---|---| | 猕猴桃 | 62mg/100g | 高温、长时间烹饪 | | 青椒 | 72-150mg | 切薄/长时加热 | | 西兰花 | 56mg | 沸水 >5 分钟损失 50% | | 橙子 | 33mg | — | | 番茄 | 19mg | 长时炖煮 | | 土豆 | 27mg | 切后长时间泡水 |

保留法:

  • ✅ **生吃**(番茄、黄瓜、彩椒)
  • ✅ **急火快炒**(断生即出锅)
  • ✅ **焯水短时**(沸水 1-2 分钟)
  • ✅ **现切现做**(切完不泡久)
  • ✅ **水加柠檬**(酸性保护维 C)
  • ❌ **避免长时间炖煮**(尤其是叶菜)
  • ❌ **避免高温 + 长时间**(油炸、烘焙)

2. 维生素 A / β-胡萝卜素(脂溶性,需油脂)

| 食物 | 含量 | |---|---| | 胡萝卜 | 4130μg/100g(β-胡萝卜素) | | 菠菜 | 487μg | | 红薯 | 710μg | | 猪肝 | 4972μg | | 蛋黄 | 438μg | | 芒果 | 1342μg |

保留法:

  • ✅ **与油脂同食**(胡萝卜用油炒;凉拌加几滴油)
  • ✅ **短时高温**(β-胡萝卜素耐热)
  • ✅ **蒸/炖**比**生吃更利于吸收**(破壁)
  • ❌ 不必担心高温破坏

3. B 族维生素(水溶性)

| 食物 | B1B2 | |---|---| | 全谷物 | 富含 | | 猪肉 | B1 高 | | 鸡蛋 | B2 高 | | 牛奶 | B2、B12 | | 绿叶菜 | 富含叶酸 |

保留法:

  • ✅ **少搓洗**(米淘 1-2 次)
  • ✅ **焯水不弃水**(不,会丢 → **应该** 短时)
  • ❌ **避免加碱**(老式玉米粥加碱,B族破坏)
  • ❌ **避免长时间高温**

4. 维生素 D / E(脂溶性)

| 食物 | 含量 | |---|---| | 三文鱼 | 526 IU/100g | | 鸡蛋黄 | 37 IU | | 香菇 | 0.4-2.5μg/100g | | 坚果、植物油 | 维生素 E |

  • ✅ **避免高温精炼油**(冷榨芝麻油更护维 E)
  • ✅ **干燥避光保存**

B. 矿物质

| 矿物质 | 食物 | 吸收率 | 关键 | |---|---|---|---| | 铁(血红素) | 菠菜 2.7mg / 猪肝 23mg / 红肉 2-3mg | 15-35% | 维 C 协助吸收 | | 铁(非血红素) | 同上 | 2-20% | 维 C 协助 | | 钙 | 牛奶 104mg / 豆腐 164mg / 虾皮 | 30-40% | 维 D 协助 | | 锌 | 牡蛎 78mg / 牛里肌 4.5mg | 30% | 动物源 > 植物源 | | 碘 | 海带 110μg / 紫菜 | 90%+ | 沿海居民不缺乏 | | 硒 | 蘑菇 0.5-2μg / 巴西坚果 / 海鲜 | 良好 | 抗氧化 | | 钾 | 香蕉 256mg / 土豆 421mg | 高 | 降血压 |

保留法:

  • ✅ **多样化**(动物 + 植物)
  • ✅ **维 C 配铁**(番茄 + 牛肉 = 强铁)
  • ✅ **连汤喝**(矿物质的 30% 在汤里)
  • ❌ **不弃汤**(矿物质水溶)

C. 多酚类与抗氧化物(抗衰老、防癌)

| 成分 | 食物 | 益处 | |---|---|---| | 番茄红素 | 番茄、西瓜 | 抗氧化、护前列腺 | | β-胡萝卜素 | 胡萝卜、菠菜 | 维 A 源 | | 花青素 | 蓝莓、紫薯、紫甘蓝、茄子皮 | 抗氧化 | | 白藜芦醇 | 葡萄(皮)、花生 | 抗氧化 | | 类黄酮 | 茶、柑橘、洋葱 | 抗炎 | | 姜黄素 | 姜黄 | 强抗炎 | | 大蒜素 | 大蒜 | 抗菌、护心血管 | | 多酚 | 茶、咖啡、巧克力、橄榄油 | 抗氧化 |

保留法:

  • ✅ **番茄做熟比番茄好**(番茄红素熟后吸收翻 3 倍)
  • ✅ **橄榄油加热**(多酚耐热)
  • ✅ **茶泡 80℃**(过高温破坏)
  • ✅ **完整带皮吃**(营养在皮)
  • ❌ **勿长期高温**(部分酚类分解)

D. 蛋白质

保留法:

  • ✅ **避免过度加热**(70℃ 以上开始变性,但完整蛋白仍可吸收)
  • ✅ **避免强酸强碱**(影响氨基酸)
  • ✅ **避免高温油炸**(蛋白变性 + 杂环胺)
  • ❌ **避免反复加热**(蛋白质氧化)

E. 膳食纤维

| 类型 | 来源 | 益处 | |---|---|---| | 可溶 | 燕麦、豆类、苹果 | 降胆固醇、稳血糖 | | 不可溶 | 全谷、蔬菜皮 | 通便 |

保留法:

  • ✅ **完整食用**(不去皮、不去麸)
  • ✅ **粗细搭配**(白米 + 糙米)
  • ✅ **全麦制品**

F. 必需脂肪酸(ω-3、ω-6)

| 类型 | 来源 | 益处 | |---|---|---| | EPA/DHA(ω-3) | 三文鱼、鲭鱼、亚麻籽、核桃 | 护脑、抗炎 | | α-亚麻酸 | 亚麻籽油、紫苏油、紫苏籽 | 心脏 | | 亚油酸(ω-6) | 玉米油、葵花油 | 过多失衡 |

建议:ω-3:ω-6 = 1:4 左右(现代人 1:20 过偏)

保留法:

  • ✅ **冷榨油**(亚麻油、紫苏油不要高温)
  • ✅ **低温烹饪**(蒸、煮、凉拌)
  • ❌ **避免高温**(高温氧化)

六、特殊人群的饮食注意

孕妇

  • ✅ **叶酸**:菠菜、芦笋、动物肝
  • ✅ **铁**:瘦肉、动物血
  • ✅ **钙**:牛奶、豆制品
  • ✅ **DHA**:三文鱼(限量)
  • ✅ **维 D**:阳光 + 蛋黄
  • ❌ **大型鱼**(汞)
  • ❌ **生食**(鱼片、半熟蛋)
  • ❌ **咖啡因**(每天 ≤200mg)
  • ❌ **酒精**(完全禁)

儿童(1-6 岁)

  • ✅ **多样化食材**(防止偏食)
  • ✅ **奶制品**(钙)
  • ✅ **蛋黄**(脑发育)
  • ❌ **整粒坚果**(窒息风险)
  • ❌ **蜂蜜**(肉毒杆菌,1 岁前)
  • ❌ **腌制**(亚硝酸盐)

老人

  • ✅ **蛋白质**(防肌肉衰减)
  • ✅ **钙 + 维 D**(防骨质疏松)
  • ✅ **易消化**:炖、煮
  • ❌ **高嘌呤**:内脏、海鲜汤
  • ❌ **油腻**

痛风

  • ❌ **内脏、海鲜、肉汤**(高嘌呤)
  • ❌ **酒**(尤其啤酒)
  • ✅ **低脂奶 + 多水**

高血脂

  • ❌ **肥肉、动物油**
  • ❌ **油炸**
  • ✅ **鱼、白肉、蔬果**

糖尿病

  • ✅ **低 GI**:粗粮、豆类
  • ❌ **白米、白糖**(单糖)
  • ✅ **高纤维**

七、传统"食物相克"是真的吗?

现代营养学基本不认同"相克"说法。大部分是巧合、过敏、过量。

常见传言 vs 真相

| 传言 | 真相 | |---|---| | 柿子 + 螃蟹 中毒 | 无证据;但螃蟹不新鲜致敏,柿子鞣酸和蛋白结合易消化不良 | | 维生素 C + 虾 中毒 | 无证据(过去传"五价砷还原三价砷",实际不可能) | | 豆浆 + 鸡蛋 降低蛋白质 | 错误;豆浆煮熟后无胰蛋白酶抑制剂,吸收更好 | | 胡萝卜 + 白萝卜 减维 C | 无证据 | | 牛奶 + 橘子 沉淀 | 蛋白 + 酸凝固(像酸奶),无害 | | 菠菜 + 豆腐 结石 | 焯水后草酸减,豆腐钙仍可吸收 | | 蜂蜜 + 大葱 中毒 | 无证据 | | 红枣 + 葱 减维 C | 无证据 | | 黄瓜 + 花生 减蛋白 | 无证据 |

真禁忌(食物搭配)

| 搭配 | 风险 | 原因 | |---|---|---| | 酒 + 头孢类抗生素 | 双硫仑样反应(休克) | 医学禁忌,致命 | | 维 A 过量 + 酒精 | 肝损伤 | 维 A 与酒精代谢竞争 | | 补铁剂 + 茶/咖啡 | 铁吸收减 | 单宁酸结合铁 | | 补铁剂 + 钙片 | 互相抑制 | 不同时间服 | | 海鲜 + 维 C 大量 | 砷中毒? | 错误(量远不够),实际安全 | | 高蛋白 + 高糖 | 消化不良 | 影响蛋白吸收,见下文 |

真正的食物禁忌很少,主要是: 1. 药物 + 食物(具体问医生) 2. 过敏原(自己清楚) 3. 食物本身毒(未熟豆角、生鱼、未熟豆浆等)

八、营养最大化的 12 条原则

  1. **多样化**(每周 25 种以上食材)
  2. **粗细搭配**(精米 + 杂粮)
  3. **生熟搭配**(能生吃生吃,该熟吃熟吃)
  4. **多蒸煮炖,少煎炸烤**
  5. **少油少盐少糖**
  6. **新鲜胜于一切**(久放营养流失、毒素累积)
  7. **现做现吃**(剩菜营养损失)
  8. **荤素搭配**(动物 + 植物蛋白)
  9. **颜色多样**(红黄绿白紫黑)
  10. **应季而食**(自然营养最高)
  11. **避免加工**(腌、熏、烤焦、过度精炼)

九、特殊食物的处理细节

1. 豆角 / 四季豆

  • **必须熟透**(含凝集素+皂苷)
  • **怎么算熟透**:**颜色由青变黄绿**,**掰断无脆感**(豆荚变软)
  • **凉拌必须焯 10 分钟以上**

2. 豆浆

  • **必须煮开**(生豆浆含胰蛋白酶抑制剂)
  • **煮沸后小火 5-10 分钟**(去泡沫)
  • **禁忌蜂蜜 + 生豆浆**(认为会中毒,实际是蛋白酶抑制剂引发)

3. 鸡蛋

  • **生鸡蛋风险**:沙门氏菌、维生素 H 抑制剂
  • **嫩煮蛋**:中心 65℃(蛋黄流动)较安全(商业巴氏蛋)
  • **全熟蛋**:中心 75℃(蛋黄凝固)安全
  • **土鸡蛋 vs 工厂蛋**:差别不大(口感、营养接近)

4. 牛奶

  • **巴氏奶**:直接饮
  • **常温奶**:可常温
  • **生奶(未消毒)**:风险高(布鲁氏菌)
  • **豆浆 ≠ 牛奶**(蛋白组成不同)

5. 大蒜

  • **生蒜**:大蒜素完整(抗菌、护心血管)
  • **熟蒜**:大蒜素减少
  • **咬碎放置 10 分钟**再吃(让蒜氨酸酶 + 蒜氨酸反应生成大蒜素)

6. 番茄

  • **生吃**:维 C 完整
  • **熟吃**:番茄红素吸收率从 5% → 30%
  • **带皮吃**:番茄红素在皮
  • **加橄榄油**:脂溶吸收

7. 胡萝卜

  • **生吃**:维 C 完整,β-胡萝卜素吸收差
  • **加油炒**:吸收翻 2-3 倍(脂溶)
  • **炖煮**:β-胡萝卜素耐热

8. 蘑菇

  • **多洗**(可能含铅)
  • **焯水**(杀菌)
  • **香菇晒后维 D 增高**(晒 1-2 小时)
  • **菇泡汤去沫**:嘌呤

9. 糙米

  • **营养更高**(维生素、矿物质、纤维)
  • **口感粗**(可先泡水 + 加水)
  • **电饭锅有"糙米档"**

10. 蛋白 vs 蛋黄

  • **蛋黄营养价值大于蛋白**(脂溶性维生素、卵磷脂、铁)
  • **蛋白几乎纯蛋白**
  • **不要丢蛋黄**

十、常见误区澄清

| 误区 | 真相 | |---|---| | "鸡汤补身体" | 鸡汤 80% 营养在肉里(蛋白、脂溶性维生素);汤里主要是水+少量水溶性物质+脂肪 | | "骨头汤补钙" | 钙不溶于水;1kg骨头汤的钙不如 1 杯牛奶(200ml) | | "水果比蔬菜营养好" | 各有强项;蔬菜总量更优;糖分水果更高 | | "野生鱼更营养" | 风险高(汞、寄生虫);养殖鱼更安全 | | "土鸡蛋 vs 普通蛋" | 差别不大,口感和心理价值 | | "速冻蔬菜营养差" | 反而更好(采后立刻冻,营养保留好) | | "反复解冻肉不能吃" | 主要是口感变、细菌风险高;已解冻即烹饪则可 | | "微波炉破坏营养" | 微波加热时间短,维 C 保留好 | | "红肉比白肉健康" | 复杂;红肉有血红素铁、维 B12,白肉脂肪少 | | "果蔬汁能排毒" | 没有"排毒"概念;纤维大部分弃 | | "素食一定健康" | 不一定;素食要搭配,否则缺蛋白、B12、铁、钙 |

十一、食材储存 × 营养保留

| 储存方式 | 影响 | 最佳 | |---|---|---| | 蔬菜室温 | 维 C 流失慢 | 阴凉通风,1-2 天 | | 蔬菜冷藏 | 维 C 保留好,但要避免冻伤 | 0-4℃,3-5 天 | | 冷冻蔬菜 | 维 C 损失 20%,但总营养好(采后立刻冻) | -18℃,6-12 月 | | 肉类冷冻 | 蛋白变性 | -18℃,3-6 月 | | 水果 | 过熟乙烯催熟 | 分开储存,避乙烯水果 |

关键

  • **采后时间 = 营养流失**(从地到嘴越短越好)
  • **温度越低 = 越保鲜**
  • **湿度适宜**(过高易霉、过低萎蔫)
  • **避免光照**(油脂氧化、维 C 分解)
  • **避免空气**(氧化)

十二、营养强化技巧(厨房小妙招)

  1. **加柠檬**:维 C 抗氧化(防变色、保留维 C)
  2. **加油**:脂溶维 A/D/E/胡萝卜素吸收
  3. **带皮吃**:葡萄、苹果、土豆带皮(洗净)
  4. **连汤喝**:矿物质在汤
  5. **现磨粉**:辣椒粉、花椒粉(香气更浓)
  6. **加发酵**:酸奶、泡菜(益生菌)
  7. **发芽**:豆芽(维 C 翻倍)
  8. **加配菜**:番茄 + 油 + 胡萝卜 = 维 A 翻倍
  9. **避免反复加热**(氧化、毒素累积)

十三、一份"营养最大化"的菜单

早餐(高蛋白 + 慢碳)

全麦面包 + 鸡蛋 + 牛奶 + 番茄
(蛋白 + 维 D + 钙 + 番茄红素 + 维 C)

午餐(均衡)

糙米饭 + 清蒸鱼 + 西兰花(加油) + 凉拌菠菜
(慢碳 + DHA + 维 C/K + 叶酸)

晚餐(轻)

小米粥 + 凉拌黄瓜 + 蒸蛋 + 豆腐汤
(易消化 + 维 C + 蛋白 + 钙)

加餐

水果(苹果/橙) + 一把坚果
(维 C + 不饱和脂肪)

十四、关于食材安全的"经验法则"

食品安全金字塔(从下到上)

                   食物中毒(关键)
                      ↑
                 储存不当
                      ↑
                 烹调不当
                      ↑

                基础卫生(洗手、洗菜板)

新鲜的食材 + 合适的处理 + 充分的加热 + 多样化进食 = 健康饮食
