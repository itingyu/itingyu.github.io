刀工技法

2026-10-07 · cooking · 厨房学 · 约 1 分钟 · 统计中…

刀工是厨师的"基本功"。切得好 = 受热均匀 = 口感一致。

刀工是厨师的"基本功"。切得好 = 受热均匀 = 口感一致。

一、刀具认知

家庭必备 3 把刀

刀具用途推荐尺寸
中式菜刀(片刀)切菜、切肉、剁骨18-20cm
日式三德刀(可选)切肉、切菜(更薄更利)18cm
水果刀/小刀削皮、剔骨、雕花10cm

进阶

  • 砍骨刀:剁大骨(厚重,新手可免)
  • 剔骨刀:精细去骨
  • 剪刀:鸡爪、剪鱼、剪葱花(超方便)
  • 刨丝器:刨丝、刨片

刀具维护

  1. 勤磨:每周磨 1-2 次
  2. 专用磨刀石:1000 目粗磨 + 3000 目精磨
  3. 磨刀棒(钢棒):日常快速复位
  4. 不切硬物(骨头用砍骨刀,冰块勿用菜刀)
  5. 用完洗净擦干(防锈)
  6. 磁吸刀架 or 刀鞘收纳

二、持刀与姿势

持刀(右手为例)

      |———食指搭刀背(稳)
      |
      |
   ———————
  |  刀柄  |  ←— 拇指食指捏刀根(精准控制)
   ———————
      |
     ===  ←— 三指握刀柄(主要力量)

核心:

  • 拇指 + 食指 捏刀根(精度控制)
  • 其余三指 握刀柄(力量)
  • 手腕 主导,手臂辅助
  • 小指/无名指 抵刀柄防滑

左手(扶料手)

关键姿势:扣指

中指弯曲 ← 抵住食材
无名指弯曲 ← 抵住食材
小指弯曲 ← 抵住食材
食指 ← 抵在食材上(感知刀距)
大拇指 ← 内收(千万别伸出去!)

作用:

  • 指节抵住刀身 → 引导厚度
  • 大拇指内收 → 防切手
  • 这是最安全的姿势

三、8 种基本刀法

1. 直切(推切)

  • 动作:刀垂直向下,顺势推拉
  • 适用:脆性食材(白萝卜、土豆、笋)
  • 节奏:匀速,不"砸"

2. 推切

  • 动作:刀尖先入,刀刃向前推,刀根切断
  • 适用:较硬或脆的食材(胡萝卜、藕)

3. 拉切

  • 动作:刀根先入,向自己方向拉
  • 适用:肉类(切肉丝、肉片)

4. 锯切

  • 动作:前后推拉(像拉锯)
  • 适用:面包、蛋糕(易碎)、冻肉

5. 铡切

  • 动作:刀平放,另一手拍刀背
  • 适用:带壳/带骨(花椒碎、花生碎、拍黄瓜)

6. 滚刀

  • 动作:边滚食材边切,每刀成块(三角形)
  • 适用:土豆、茄子、笋(红烧)

7. 剁

  • 动作:刀举高,用力下剁
  • 适用:肉馅、肉末

8. 片(斜刀片/平刀片)

  • 斜刀片:刀与菜板呈 30°,片出椭圆片(鱼肉、肉片)
  • 平刀片:刀平,片出薄片(豆腐、里脊)

四、10 种成形

形状大小适用菜
末(碎末)< 3mm蒜末、姜末
粒3-5mm葱粒
丁(小方块)1-2cm土豆丁、萝卜丁
块(大块)3-5cm红烧肉块
条0.5×0.5×4cm土豆条
丝0.3×0.3×5cm土豆丝、青椒丝
薄片2-3mm肉片
厚片4-5mm土豆片
茸(泥)完全碎姜茸、肉泥
花刀(麦穗、菊花、荔枝)美观鱿鱼、腰花、萝卜

"切丝"流程示范

原料(长条形,如土豆、胡萝卜)
   ↓ 切片(3mm 厚)
   ↓ 码齐
   ↓ 切片(3mm 宽)
   ↓ 切丝(3mm × 3mm × 5cm)

切丝三件套:稳、匀、净(不连刀)

五、不同食材的刀工要点

肉类

处理关键作用
横切牛肉(垂直纤维)牛肉纤维粗,横切才嫩不塞牙
顺切猪肉(沿纤维)猪肉纤维细,顺切保持型不碎
斜切鸡肉(斜纹)鸡胸嫩,顺切易散整齐
鱼:片鱼片要斜刀角度 30°,一刀推到底薄而不碎
冻肉:半冻切不软不硬,片得整齐厚度一致

蔬菜

处理关键
白菜帮:斜切(切断纤维更好入味)入味快
土豆:去皮、切片、泡水去淀粉防氧化、防黏
葱:直切葱花,葱白切马耳形配菜好看
蒜:先拍碎再切末易切、出味
姜:先切片 → 切丝 → 切末用途分级
辣椒:直刀剖开,去籽切片去辣配菜

豆腐

  • 嫩豆腐:用刀平铲(不要压)
  • 老豆腐:横竖切丁,大小一致
  • 日本豆腐:切段 + 裹粉再煎

六、刀工与火候的关系

关键认知:形状决定受热时间

形状厚度加热时间适合
末<3mm<1 分钟爆香、勾芡
丝3mm1-2 分钟爆炒
薄片2-3mm30 秒 - 1 分钟滑炒
丁1-2cm3-5 分钟烧、炒
块3-5cm10-30 分钟红烧
整只(鸡/鱼)全30-60 分钟炖、整烧

原则:

  • 同一锅食材大小一致 → 同时熟
  • 薄易熟厚耐炖 → 分批下料

七、安全与防护

切手原因

  1. 左手大拇指伸出去(最常见)
  2. 手指没扣
  3. 刀钝(钝刀才更危险,会滑)
  4. 菜板湿滑
  5. 走神/玩手机

应急处理

  • 小伤口:清水冲 → 碘伏消毒 → 创可贴
  • 深伤口:压迫止血 → 去医院
  • 菜板湿滑:垫湿毛巾/防滑垫

八、刀工练习法

入门练习(每天 10-15 分钟)

  1. 切土豆丝:从粗到细,目标 3mm×3mm×5cm 整齐
  2. 切葱花:0.3cm 均匀
  3. 切姜末:细到 1mm
  4. 切肉片:厚薄一致(2mm)
  5. 切肉丝:先切片,再叠切丝

进阶练习

  1. 花刀:麦穗花刀(腰花)、菊花花刀(鱿鱼)、荔枝花刀(萝卜)
  2. 蓑衣刀:刀面斜切 90° 转 45° 反复(整黄瓜/茄子)
  3. 整齐度:30 秒内切 50 根土豆丝粗细一致
  4. 速度:在保证整齐的前提下提速

检验标准

切土豆丝 0.5cm 宽、3mm 厚、长短一致 = 刀工合格

九、刀工工具辅助

  • 防滑垫(湿毛巾也行):防滑
  • 护指器(不锈钢):新手防切手
  • 手动切丝器:切土豆丝、萝卜丝(均匀但慢)
  • 多功能刨:刨丝刨片
  • 厨房剪刀:鸡翅剪段、鱼剖肚、葱花剪碎

十、不同菜系的刀工差异

菜系风格特点
粤菜精细切丝细如发,讲究"薄、透、匀"
鲁菜整齐大方、刀口清楚、规格一致
川菜麻利速度快,大小均匀即可
淮扬刀工见长文思豆腐:一块豆腐切 5000 丝
东北豪放大块、大片(乱炖)
江浙细致讲究色泽和形态

十一、刀工"九字诀"

稳、准、匀、快、利、净、薄、整、齐
  • 稳:不抖,握刀稳
  • 准:刀口准,不走偏
  • 匀:厚薄均匀
  • 快:在稳准匀基础上的速度
  • 利:切完不黏连
  • 净:断面干净,不撕扯
  • 薄:该薄则薄
  • 整:该整则整(整鸡、整鱼)
  • 齐:形态整齐
