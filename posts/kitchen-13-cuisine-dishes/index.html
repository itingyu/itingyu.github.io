八大菜系代表菜家常做法

2026-10-07 · cooking · 厨房学 · 约 1 分钟 · 统计中…

上一份讲"是什么",这份讲"怎么做"。 选取各菜系家庭厨房可复制的代表菜,详细到能下锅。

选取各菜系家庭厨房可复制的代表菜,详细到能下锅。

通用提示

  • 家用火力比餐厅弱,时间适当延长 30-50%
  • 没有大锅气(火力不够),但可以多油少做(覆盖食材)
  • 调料减半起(餐厅重,家庭宜减)
  • 困难菜找简版

一、鲁菜(山东菜)

1. 糖醋鲤鱼

难度:★★★★ | 时间:40 分钟

材料(2-3 人份)

  • 鲤鱼 1 条(草鱼亦可,600-800g)
  • 葱姜蒜末各 10g
  • 糖 50g,醋 50ml,生抽 20ml,料酒 15ml
  • 盐 3g,淀粉 100g,面粉 50g,水 80ml(糊)
  • 油多量(炸用)

步骤

1. 鱼去鳞、腮、内脏、黑膜(关键),两面划花刀(斜 3 刀)
2. 鱼身抹盐 + 料酒腌 10 分钟
3. 调脆糊:淀粉+面粉+少许盐+水,稠糊状
4. 鱼裹满糊(挂满)
5. 油温七成(170℃)→ 鱼下锅 → 炸 5-7 分钟定型
   → 捞出 → 油温升到八成 → 复炸 30 秒上色 → 捞出控油
6. 锅留底油 → 葱姜蒜末爆香
7. 加糖+醋+生抽+料酒+水(150ml)→ 烧开
8. 湿淀粉勾芡(分次)→ 汁冒泡变稠
9. 浇在鱼身上 → 完成

关键:复炸让外壳酥脆;糖醋汁糖:醋=1:1,起泡即浇

2. 九转大肠(简版)

难度:★★★★ | 时间:60 分钟

材料

  • 熟大肠 500g(超市有售半成品)
  • 葱姜蒜末各 10g
  • 糖 30g,醋 15ml,生抽 20ml,老抽 5ml
  • 料酒 15ml,盐 2g

步骤

1. 大肠切 2cm 段,沸水焯 1 分钟去油
2. 锅烧热 → 不放油 → 大肠下锅 → 小火煎出油(微焦)
3. 加葱姜蒜末
4. 加糖(炒到焦糖色)→ 加醋、生抽、老抽、料酒
5. 加水没过 → 大火烧开 → 转小火炖 30 分钟
6. 大火收汁 → 汁浓挂勺
7. 出锅撒胡椒粉(九转之名取自九道工序)

3. 葱烧海参(简版)

难度:★★★★ | 时间:40 分钟

材料

  • 即食海参 3-4 只(泡发或半成品)
  • 大葱 3 根(切马耳段)
  • 高汤 200ml(或鸡精 1g + 热水)
  • 糖 5g,生抽 15ml,老抽 5ml,料酒 10ml
  • 蚝油 10g,盐 2g

步骤

1. 海参焯水 1 分钟
2. 锅多油 → 葱段下锅 → 中火慢煎到焦黄(葱油)
3. 葱段捞出,余油爆香 → 加姜
4. 加海参翻匀
5. 加高汤+糖+生抽+老抽+料酒+蚝油
6. 小火煨 10 分钟 → 入味
7. 大火收汁 → 浓稠挂勺
8. 出锅撒新葱花

4. 四喜丸子

难度:★★★ | 时间:50 分钟

材料

  • 猪肉馅 400g(三肥七瘦)
  • 鸡蛋 1 个,葱姜末各 15g
  • 淀粉 30g,生抽 20ml,老抽 10ml
  • 盐 3g,糖 10g,料酒 15ml,八角 1 颗

步骤

1. 肉馅 + 葱姜末 + 鸡蛋 + 淀粉 + 盐 + 生抽 + 料酒
   → 顺时针搅至起胶(出黏性)
2. 团成 4 个大丸子(约 100g/个)
3. 油温六成 → 丸子下锅 → 中火煎到金黄定型
4. 锅留底油 → 加八角 + 葱姜爆香
5. 加水 + 糖 + 老抽 + 盐
6. 丸子回锅 → 大火烧开 → 转小火炖 30 分钟
7. 大火收汁 → 出锅

二、川菜(四川菜)

1. 麻婆豆腐

难度:★★★ | 时间:20 分钟

材料

  • 嫩豆腐 1 盒(400g)
  • 牛肉末(或猪肉末)100g
  • 郫县豆瓣酱 20g,豆豉 5g
  • 蒜末 10g,姜末 5g,葱花 10g
  • 花椒粉 2g
  • 生抽 10ml,糖 3g,水淀粉 20ml

步骤

1. 豆腐切 1.5cm 丁 → 沸水焯 2 分钟(加盐防碎)→ 捞出
2. 热锅 → 油 → 肉末下锅 → 中火煸到焦香 → 盛出
3. 余油 → 豆瓣酱+豆豉+蒜末+姜末 → 小火炒红油
4. 加生抽+糖+热水(200ml)
5. 豆腐下锅 → 中火煮 5 分钟
6. 肉末回锅 → 翻匀
7. 淋水淀粉(分 3 次)→ 浓稠挂勺
8. 关火 → 撒花椒粉+葱花

2. 回锅肉

难度:★★★ | 时间:30 分钟

材料

  • 五花肉 300g(带皮)
  • 蒜苗 150g(切马耳段)
  • 郫县豆瓣酱 20g,甜面酱 10g
  • 生抽 10ml,糖 5g,料酒 10ml
  • 豆豉 5g,姜 3 片

步骤

1. 五花肉冷水下锅 → 姜片+料酒 → 煮 15 分钟(八成熟)
2. 捞出 → 切 3mm 薄片(灯盏窝)
3. 锅烧热 → 不放油 → 肉片下锅 → 小火煸到微卷出油
4. 加豆瓣酱+豆豉 → 炒红油
5. 加甜面酱+糖 → 翻匀
6. 蒜苗下锅 → 大火快炒(蒜白先下,蒜叶后下)
7. 生抽提鲜 → 出锅

关键:肉要煸出"灯盏窝"(卷曲)才有灵魂;蒜苗分两次下

3. 宫保鸡丁

难度:★★★ | 时间:20 分钟

材料

  • 鸡腿肉 200g(切 1.5cm 丁)
  • 花生米 50g,大葱白 1 根(马耳段)
  • 干辣椒 6-8 个,花椒 20 粒,蒜片 10g,姜片 5g
  • 生抽 15ml,醋 15ml,糖 10g,料酒 10ml
  • 盐 2g,水淀粉 20ml

腌肉:盐+料酒+生抽+淀粉+油,15 分钟

步骤

1. 调汁:酱油+醋+糖+料酒+水淀粉 → 备用(关键)
2. 热锅 → 多油 → 油温五成 → 鸡丁下锅 → 大火滑到变色 → 盛出
3. 余油 → 干辣椒+花椒 → 小火炒深红
4. 加姜蒜片 → 爆香
5. 鸡丁回锅 → 大火快炒
6. 葱段下锅 → 翻匀
7. 淋调汁 → 快速翻匀
8. 花生米下锅 → 出锅

4. 鱼香肉丝

难度:★★★ | 时间:20 分钟

材料

  • 里脊肉 200g(切丝)
  • 木耳 30g(泡发切丝),胡萝卜 50g(切丝),青椒 50g(切丝)
  • 泡椒末 15g(剁椒也行),葱姜蒜末各 10g
  • 生抽 15ml,醋 15ml,糖 10g,料酒 10ml

步骤

1. 肉丝腌制(同宫保鸡丁)
2. 调汁(同宫保鸡丁)
3. 锅热 → 多油 → 肉丝滑油 → 盛出
4. 余油 → 泡椒末+葱姜蒜末 → 小火炒香
5. 加胡萝卜丝 → 炒到断生
6. 加木耳+青椒 → 翻匀
7. 肉丝回锅 → 翻匀
8. 淋调汁 → 快速翻匀 → 出锅

5. 水煮肉片(简版)

难度:★★★★ | 时间:30 分钟

材料

  • 猪里脊 300g(切薄片)
  • 豆芽 100g(垫底),生菜 100g
  • 郫县豆瓣酱 30g,干辣椒 5 个,花椒 20 粒,蒜末 15g
  • 生抽 10ml,料酒 10ml,蛋清 1 个,淀粉 20g

步骤

1. 肉片腌制:盐+料酒+蛋清+淀粉+油 → 15 分钟
2. 蔬菜沸水焯 → 铺盆底
3. 锅热 → 油 → 豆瓣酱炒红油
4. 加水(或高汤)500ml + 生抽 → 烧开
5. 肉片逐片下锅(不要搅)→ 煮到变白 → 倒入蔬菜盆
6. 撒蒜末+花椒+干辣椒在肉上
7. 烧热油(180℃)→ 浇在蒜末上(刺啦一声)→ 完成

6. 酸菜鱼(简版)

难度:★★★★ | 时间:30 分钟

材料

  • 草鱼片 400g(切 3mm 厚)
  • 酸菜 200g(切段),泡椒 5 个(切碎)
  • 姜蒜末各 10g,干辣椒 5 个,花椒 10 粒
  • 料酒 15ml,蛋清 1 个,淀粉 20g,白醋 5ml

步骤

1. 鱼片腌制:盐+料酒+蛋清+淀粉+油 → 10 分钟
2. 锅热 → 油 → 姜蒜+泡椒 → 爆香
3. 加酸菜 → 中火炒 3 分钟(出香味)
4. 加水(800ml) → 烧开 → 小火煮 10 分钟
5. 调盐+白醋 → 把酸菜汤味调好
6. 鱼片逐片下锅(不要搅)→ 煮 1 分钟 → 关火
7. 倒盆里 → 撒花椒+干辣椒+蒜末
8. 烧热油浇上 → 完成

7. 夫妻肺片(凉菜)

难度:★★ | 时间:30 分钟

材料

  • 牛肉/牛杂卤熟 300g(卤味店买,或买熟食)
  • 花生碎 30g,香菜 10g
  • 红油 30ml,生抽 15ml,醋 10ml,糖 3g
  • 花椒粉 1g,蒜末 5g,葱花 5g

步骤

1. 熟牛肉切薄片
2. 调汁:红油+生抽+醋+糖+花椒粉+蒜末 → 拌匀
3. 牛肉片 + 调汁 → 拌匀
4. 装盘 → 撒花生碎+香菜+葱花

8. 口水鸡(凉菜)

难度:★★★ | 时间:40 分钟

材料

  • 鸡腿 2 只(约 400g)
  • 花生碎 30g,芝麻 5g,葱花 5g
  • 红油 30ml,生抽 15ml,醋 10ml,糖 5g
  • 花椒粉 1g,蒜末 5g,芝麻酱 5g

步骤

1. 鸡腿冷水下锅 + 姜片 → 煮开 → 转小火煮 15 分钟
2. 关火 → 焖 10 分钟(用余温熟)
3. 捞出 → 冰水过凉(皮爽)
4. 切件(摆盘)
5. 调汁(红油+生抽+醋+糖+花椒粉+蒜末+芝麻酱+少许鸡汤)
6. 浇在鸡上 → 撒花生碎+芝麻+葱花

三、粤菜(广东菜)

1. 白切鸡

难度:★★ | 时间:40 分钟

材料

  • 走地鸡 1 只(1500g 左右),不能用冷冻鸡
  • 姜 50g(切末),葱 50g(切末)
  • 盐 3g,糖 3g,花生油 30ml(蘸料)

蘸料:姜末+葱末+盐+糖+热油泼

步骤

1. 鸡清洗 → 去内脏 → 鸡脚塞进肚内
2. 大锅水(够没过鸡) → 烧开 → 关火
4. 抓住鸡头把鸡浸入 → 提起来 → 再浸(反复 3 次,内外温度一致)
5. 整只鸡下锅 → 盖盖 → 关火 → 浸泡 30 分钟
6. 捞出 → 冰水过凉(锁皮,皮爽脆)
7. 沥干 → 切件(带骨带皮)
8. 蘸料:姜葱末+盐+糖 → 烧热油浇上 → 沾鸡吃

关键:"浸"法(关火泡熟)让肉嫩多汁

2. 蚝油生菜(广东家常)

难度:★ | 时间:5 分钟

材料

  • 生菜 1 颗(约 300g)
  • 蚝油 15g,生抽 5ml,糖 3g,蒜末 5g
  • 水淀粉 10ml

步骤

1. 生菜掰大块 → 洗净
2. 沸水 + 油 + 盐 → 生菜下锅 → 焯 30 秒 → 捞出摆盘
3. 锅烧热 → 油 → 蒜末爆香
4. 加蚝油+生抽+糖+水(50ml)→ 烧开
5. 水淀粉勾薄芡 → 浇生菜上

3. 蒜蓉蒸虾

难度:★★ | 时间:10 分钟

材料

  • 大虾 8-10 只(基围虾)
  • 蒜 1 头(切末),葱丝少许
  • 生抽 10ml,蚝油 5g,糖 3g,油 30ml

步骤

1. 虾剪须、开背 → 去虾线
3. 蒜末+油(20ml)+盐+糖 → 拌匀(蒜油)
4. 虾摆盘(开背向上)→ 蒜油铺虾上
5. 水烧开 → 上锅 → 蒸 6-7 分钟
6. 取出 → 撒葱丝
7. 烧热油 → 浇葱丝上(刺啦)
8. 淋生抽

### 4. 煲仔饭

**难度**:★★ | **时间**:30 分钟

**材料**
- 大米 200g
- 腊肠 2 根(切片),腊肉 100g(切块),香菇 5 朵(泡发切)
- 油菜 2 棵,鸡蛋 1 个(可选)
- 生抽 20ml,蚝油 10g,糖 3g,香油 5ml

**步骤**
  1. 大米淘洗 → 加水(水米比 1:1.2)→ 砂锅泡 30 分钟
  2. 大火烧开 → 转小火煮 8 分钟(米半熟)
  3. 摆上腊肠+腊肉+香菇 → 盖盖 → 小火 5 分钟
  4. 沿锅边淋一圈油(出锅巴关键)→ 再煮 5 分钟
  5. 关火 → 焖 10 分钟 → 打入鸡蛋(可)
  6. 小油菜焯水铺上
  7. 调汁:生抽+蚝油+糖+香油+少许水 → 浇饭上 ```

5. 蜜汁叉烧(简版)

难度:★★★ | 时间:50 分钟(腌 4 小时)

材料

  • 梅花肉 500g(切长条)
  • 叉烧酱 100g(瓶装),蜂蜜 30g
  • 生抽 15ml,料酒 15ml,蒜末 10g

步骤

1. 肉 + 叉烧酱 + 生抽 + 料酒 + 蒜末 → 腌 4 小时(过夜更好)
2. 烤箱预热 200℃
3. 烤盘铺锡纸 → 摆肉条
4. 烤 15 分钟 → 取出刷蜂蜜
5. 翻面再烤 10 分钟 → 刷蜂蜜
6. 再烤 5 分钟 → 上色
7. 切件 → 装盘

6. 白灼虾

难度:★ | 时间:5 分钟

材料

  • 活基围虾 500g
  • 姜丝、葱丝、生抽、香油

步骤

1. 大锅水烧开 + 姜片 + 料酒
2. 虾下锅 → 煮到变红卷曲(约 2 分钟)→ 捞出冰水过凉
3. 蘸料:生抽+姜丝+葱丝+香油

四、苏菜(淮扬菜)

1. 红烧狮子头(蟹粉版简版)

难度:★★★ | 时间:80 分钟

材料

  • 五花肉馅 400g(三肥七瘦,切丁,不要纯绞)
  • 蟹粉 30g(可选,加更香),荸荠 3 个(切丁,加脆)
  • 葱姜末 20g,鸡蛋 1 个,淀粉 20g
  • 生抽 20ml,老抽 10ml,糖 10g
  • 高汤 400ml

步骤

1. 肉丁 + 荸荠丁 + 葱姜末 + 鸡蛋 + 淀粉 + 生抽
   → 顺时针搅上劲(出胶)
2. 团成 4 个大丸子(200g/个)
3. 油温六成 → 煎到表面金黄定型
4. 砂锅(或深锅)铺白菜叶 + 葱姜
5. 摆入丸子 → 加高汤 + 生抽 + 老抽 + 糖 + 料酒
6. 大火烧开 → 转小火炖 60 分钟
8. 出锅(整颗完整)

2. 松鼠鳜鱼(简版 · 用草鱼)

难度:★★★★ | 时间:40 分钟

材料

  • 草鱼 1 条(600-800g)
  • 番茄酱 30g,糖 50g,醋 30ml,生抽 10ml
  • 淀粉 100g,面粉 30g,水 80ml
  • 葱姜蒜末

步骤

1. 鱼去鳞、腮、内脏、黑膜(关键)
2. 鱼头切下 → 鱼身沿脊骨片开(不切断)→ 成蝴蝶状
3. 在鱼肉上切菱形花刀(斜切不断皮)→ 反方向再切(成菱形块)
4. 鱼身抹盐+料酒腌 5 分钟
5. 拍干淀粉(拍满每个菱形格)
7. 油温七成 → 拎鱼尾下锅(定型)→ 炸 8 分钟 → 捞出
8. 油温升到八成 → 复炸 30 秒 → 装盘成松鼠尾翘状
9. 锅留底油 → 葱姜蒜爆香
10. 加番茄酱+糖+醋+生抽+水 → 烧开
11. 湿淀粉勾芡 → 浇鱼上 → 完成

关键:菱形花刀让它"开花"

3. 扬州炒饭

难度:★★ | 时间:15 分钟

材料

3. 砂锅 + 肉 + 香料包 + 葱姜
4. 加冰糖+生抽+老抽+料酒+盐+水(没过肉)
5. 大火烧开 → 转小火炖 60 分钟(腊汁)
6. 肉捞出 → 切碎(剁碎,带汤汁)
7. 白吉馍横切 → 不切断
9. 把肉夹进馍里 → 浇一勺汤汁

8. 长沙:臭豆腐

难度:★★★ | 时间:30 分钟

材料

  • 长沙臭豆腐生胚(网购或超市)
  • 辣椒酱,香菜,榨菜末

步骤

1. 臭豆腐生胚 → 油温六成 → 下锅 → 中火炸
2. 炸到外壳金黄酥脆(约 3 分钟)→ 捞出
4. 戳洞(让酱进去)
5. 灌入辣椒酱 + 撒榨菜 + 香菜

9. 云南:汽锅鸡(简版)

难度:★★★ | 时间:3 小时

材料

  • 整鸡半只(切块)
  • 姜片 20g,葱段 20g,盐 5g

步骤

1. 鸡块 + 姜葱 → 摆入汽锅(中间有个气嘴的锅)
2. 不加一滴水
3. 大锅加水 → 架上汽锅
4. 大火烧开 → 转小火 → 蒸 3 小时
5. 蒸汽通过气嘴滴入汽锅 → 形成原汁鸡汤
6. 加盐调味 → 出锅(汤清如水,味浓似鸡精)

难度菜适合
★蚝油生菜、白灼虾、油泼面、辣椒炒肉、海蛎煎、腊味合蒸第一周练习
★★蒜蓉蒸虾、白切鸡、扬州炒饭、煲仔饭、鱼香肉丝1 月后
★★沙茶面、毛豆腐、肉夹馍、京酱肉丝1 月后

★★★糖醋鲤鱼、四喜丸子、东坡肉、锅包肉、毛氏红烧肉1-3 月
★★★★松鼠鳜鱼、九转大肠、水煮鱼、酸菜鱼、佛跳墙进阶

十一、做菜的心得

不是学一道菜,是学一类方法。
  • 回锅肉 ↔ 麻婆豆腐:都是豆瓣酱炒红油起手
  • 红烧肉 ↔ 红烧排骨:都是糖色 + 小火炖
  • 白切鸡 ↔ 白灼虾:都是"水煮"或"浸熟"
  • 西湖醋鱼 ↔ 糖醋鲤鱼:都是糖醋汁浇淋
  • 宫保鸡丁 ↔ 鱼香肉丝:都是调汁预制 + 速炒

学会 3 道,会做 30 道。
