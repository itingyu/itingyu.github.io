中国八大菜系详解

2026-10-07 · cooking · 厨房学 · 约 1 分钟 · 统计中…

一方水土养一方菜。中国菜的差异根子源于水土、气候、食材、调味料、习俗的差异。

一方水土养一方菜。中国菜的差异根子源于水土、气候、食材、调味料、习俗的差异。

一、八大菜系总览

四大菜系(老说法)

鲁、川、粤、苏(淮扬)

八大菜系(经典说法,1965 年首次提出)

序号菜系别称起源地风味
1鲁菜山东菜山东(济南、胶东、孔府)咸鲜、葱香
2川菜四川菜四川(成都、重庆)麻辣、鱼香
3粤菜广东菜广东(广州、潮州、东江)清淡、鲜香
4苏菜淮扬菜江苏(扬州、淮安)清雅、平和
5闽菜福建菜福建(福州、闽南、闽西)鲜咸、汤多
6浙菜浙江菜浙江(杭州、宁波、绍兴)鲜嫩、清爽
7湘菜湖南菜湖南(湘江、洞庭、湘西)香辣、酸辣
8徽菜安徽菜安徽(皖南、皖江)重油、重色

十二大菜系(新说法)

加上:京、沪、东北、豫(还有鄂、赣、陕 等)

二、地理与风味的关系

为什么口味是这样的?
地区气候食材特点口味偏好
北方(鲁、京、东北)寒冷干燥小麦、葱蒜、白菜、土豆咸、浓、香
西北(陕、新)干燥寒冷牛羊肉、面食重口味、孜然
长江中下游(苏、浙、沪)温润潮湿鱼米、河鲜清淡、咸鲜、甜
西南(川、渝)潮湿阴冷辣椒、姜蒜、花椒麻辣(驱寒祛湿)
华南(粤、闽、台)炎热鲜活海产清淡、生鲜
华中(湘、鄂、赣)潮湿鲜辣、肉食香辣、酸辣
华东山区(徽)山区山珍、腌腊重油重色

一句话理解

  • 沿海:清淡(海鲜本味)
  • 山区:重口(就地取材,保存需求)
  • 寒冷:浓郁(高热量抗寒)
  • 湿热:麻辣(祛湿散热)

三、八大菜系分述

1. 鲁菜(山东菜)

别称:山东菜、北菜之祖(宫廷菜之根)

起源地:山东(济南、胶东、孔府)

核心风味:

  • 咸鲜为主,讲究火候与刀工
  • 葱香浓郁(大葱是灵魂)
  • 高汤的鼻祖(吊汤)
  • 原汁原味

代表技法:爆、烧、炸、扒、熘、拔丝

代表菜:

菜名特点
糖醋鲤鱼鲁菜之首,糖醋代表菜
九转大肠复合味,色泽红亮
葱烧海参葱香 + 海参嫩滑
油爆双脆极考火候(肚仁+鸭胗)
德州扒鸡五香脱骨,名扬天下
四喜丸子婚宴必备
糖醋里脊(鲁版)色泽、口感讲究
孔府一品锅(孔府菜)奢华官府菜

特色食材:章丘大葱、胶东海参、莱阳梨、青岛啤酒鸡

名厨:王义均、屈浩

家常示范:葱烧海参

海参泡发 + 焯水 → 葱段炒香 + 海参下锅 →
加高汤 + 糖 + 酱油 → 小火烧入味 → 大火收汁

2. 川菜(四川菜)

起源地:四川(成都、重庆)

核心风味:

  • 麻辣(花椒 + 辣椒)+ 鲜香
  • 复合味型丰富:鱼香、麻辣、宫保、怪味、家常、红油
  • "一菜一格,百菜百味"
  • 味型多达 23 种

代表技法:小炒、干煸、烧、烩、炸收

味型一览:

味型主味代表菜
麻辣麻辣水煮鱼、麻婆豆腐
鱼香咸甜酸辣鱼香肉丝
宫保糊辣荔枝宫保鸡丁
怪味多味合一怪味鸡
家常微辣咸鲜回锅肉
红油辣 + 香红油肚丝
酸辣酸辣酸辣汤、酸辣土豆丝
椒麻花椒 + 麻椒椒麻鸡
蒜泥蒜香蒜泥白肉
麻辣麻辣夫妻肺片
糖醋糖醋糖醋排骨
咸鲜咸鲜鲜笋鱼

代表菜:

菜备注
麻婆豆腐川菜名片,麻辣烫代表
水煮鱼川式水煮,红油浓汤
回锅肉蒜苗 + 豆瓣酱爆炒
宫保鸡丁糊辣荔枝味代表
鱼香肉丝鱼香味鼻祖
夫妻肺片红油凉菜代表
开水白菜看似清水,实则顶汤
辣子鸡干辣椒裹鸡
酸菜鱼重庆风味
冷锅兔/串串成都夜宵

特色食材/调料:

  • 郫县豆瓣酱(川菜灵魂)
  • 汉源花椒(麻味正)
  • 二荆条辣椒(香辣不猛)
  • 七星椒(辣度高)
  • 泡椒、泡姜(泡菜文化)
  • 麻辣火锅

名厨:陈麻婆(麻婆豆腐)、史正良(开水白菜)

家常示范:回锅肉

五花肉煮熟切薄片 + 豆瓣酱炒红油 →
+ 蒜苗 + 甜面酱 + 酱油 → 出锅

3. 粤菜(广东菜)

起源地:广东(广府、潮州、东江、客家)

核心风味:

  • 清淡、鲜美
  • 生猛(新鲜活物)
  • "食在广州"
  • 注重食材本味

三大流派:

  • 广府菜:广州为代表,清淡鲜美(白切鸡、清蒸鱼)
  • 潮汕菜:鲜咸浓香(牛肉火锅、生腌)
  • 客家菜:咸香肥(咸鸡、梅菜扣肉)
  • 东江菜:咸、酸、辣

代表技法:白灼、清蒸、煲、焗、炒、煲、烤

代表菜:

菜备注
白切鸡姜葱蘸料,皮爽肉嫩
烧鹅(深井烧鹅)皮脆肉香
蜜汁叉烧甜咸玫瑰
清蒸石斑鱼原汁原味
蒜蓉蒸虾经典粤菜
白灼虾蘸料简单,虾鲜
潮汕牛肉火锅鲜切牛肉,牛肉丸
蚝油生菜广东家常
煲仔饭砂锅饭,锅巴香
肠粉早茶灵魂
菠萝咕噜肉酸甜口(中外通吃)
早茶(虾饺、烧卖、叉烧包)粤式文化
老火靓汤慢炖养生

特色食材/调料:

  • 蚝油(提鲜灵魂)
  • 生抽、老抽、糖(调味基础)
  • 玫瑰露酒、米酒
  • 海鲜(鲜活为王)
  • 砂锅/瓦煲

名厨:顺德师傅、镛记

家常示范:白切鸡

整鸡(走地鸡) → 冷水下锅 → 小火浸煮 → 关火焖熟 →
冰水过凉(锁皮) → 切件 → 姜葱蘸料

4. 苏菜(淮扬菜)

起源地:江苏(扬州、淮安)、上海一带

核心风味:

  • 清雅平和、浓而不腻
  • 刀工见长(文思豆腐)
  • 汤菜最醇(拆烩鱼头)
  • 偏甜(扬州、盐城较甜,南京偏咸)

代表技法:炖、焖、煨、焐

代表菜:

菜备注
狮子头(蟹粉狮子头)大肉圆炖 4 小时
松鼠鳜鱼形似松鼠,酸甜
文思豆腐一块豆腐切 5000 丝
盐水鸭(南京)鸭界代表
金陵烤鸭早于北京烤鸭
清炖蟹粉狮子头功夫菜
鸡汤煮干丝早茶菜
扬州炒饭鸡蛋 + 火腿 + 虾仁
清蒸鲥鱼古时贡品
拆烩鲢鱼头鱼头 + 火腿 + 冬笋
梁溪脆鳝无锡酥脆鳝鱼

特色食材:

  • 扬州鹅
  • 太湖银鱼
  • 高邮咸蛋(袁枚《随园食单》)

名厨:王沂庆(清)、谢霆锋(综艺)

家常示范:文思豆腐汤

嫩豆腐 → 横竖切 5000 丝(1mm 细丝)→
+ 高汤煮开 + 冬菇丝 + 笋丝 + 火腿丝 →
+ 盐 → 蛋清勾薄芡 → 出锅

5. 闽菜(福建菜)

起源地:福建(福州、闽南、闽西)

核心风味:

  • 鲜、淡、甜
  • 汤菜见长(福建汤全国最考究)
  • 海鲜丰富(海产多样)

三大流派:

  • 福州菜:清淡鲜爽
  • 闽南菜:海味为主
  • 闽西菜:山珍为主(客家源流)

代表技法:汤、炖、炒、炸、炝

代表菜:

菜备注
佛跳墙闽菜之巅,百料百汤
荔枝肉形似荔枝,酸甜
海蛎煎(蚵仔煎)闽台名小吃
沙茶面闽南日常
福建肉燕形似燕窝
醉排骨醉 + 炸 + 卤
鸡汤汆海蚌汤清味鲜
南煎肝肠闽东菜

特色食材/调料:

  • 沙茶酱(闽南)
  • 红糟(酒糟,闽东)
  • 福建鱼丸、肉燕
  • 武夷山笋

名厨:蔡敬清等

家常示范:海蛎煎

鲜海蛎 + 鸡蛋 + 地瓜粉 → 摊平煎 →
+ 甜辣酱 → 出锅

6. 浙菜(浙江菜)

起源地:浙江(杭州、宁波、绍兴)

核心风味:

  • 鲜、嫩、爽、脆
  • 讲究本味
  • "鱼米之乡"

三大流派:

  • 杭帮菜:清淡精致(西湖醋鱼)
  • 宁波菜:鲜咸合一(雪菜黄鱼)
  • 绍兴菜:酱醉风味(梅干菜)

代表技法:炒、炸、烩、焖、烧

代表菜:

菜备注
西湖醋鱼草鱼活杀,醋香
龙井虾仁茶香入菜
东坡肉苏轼创制
叫花鸡荷叶泥土包裹烤
宋嫂鱼羹酸咸鱼羹
干炸响铃豆皮卷肉馅炸脆
宁波汤圆小吃代表
梅干菜烧肉绍兴代表
雪菜黄鱼宁波代表
西湖莼菜汤滑嫩汤品

特色食材:

  • 西湖龙井(茶)
  • 绍兴黄酒
  • 金华火腿
  • 钱塘江鲜、千岛湖鱼

名厨:胡忠英(杭帮菜元老级)

家常示范:龙井虾仁

活虾剥壳去虾线 + 蛋清上浆 →
+ 龙井茶泡水(80℃,取茶汁)→
滑油 → 茶汁 + 茶尖入锅 → 翻匀

7. 湘菜(湖南菜)

起源地:湖南(湘江、洞庭湖、湘西)

核心风味:

  • 香辣、酸辣
  • 油重色浓
  • 腊味丰富

三大流派:

  • 湘江流域:鲜辣为主(剁椒鱼头)
  • 洞庭湖区:鱼菜为主
  • 湘西山区:腊味、腌菜

代表技法:腊味、剁椒、煸炒、烧、蒸

代表菜:

菜备注
剁椒鱼头湘菜名片,鲜辣
腊味合蒸腊肉+腊鱼+腊鸡
湘西外婆菜腌菜炒肉
毛氏红烧肉毛泽东喜爱(湖南)
口味虾长沙夜宵
永州血鸭湘西代表
湘西酸鱼苗家酸味
东安子鸡湘江代表
辣椒炒肉湖南家常
臭豆腐(长沙)黑色经典

特色食材/调料:

  • 剁椒(湘菜之魂)
  • 湘西腊肉(柴火熏)
  • 浏阳豆豉
  • 酸辣子(苗家)
  • 辣妹子、老干妈(湖南品牌)

名厨:许菊云(湘菜大师)

家常示范:剁椒鱼头

大鱼头 + 料酒、姜、葱铺底 →
+ 大量剁椒 + 蒜末 + 豆豉 → 蒸 10-12 分钟 →
+ 热油激葱花 → 出锅

8. 徽菜(安徽菜)

起源地:安徽(皖南、皖江、皖北)

核心风味:

  • 重油、重色(火腿佐味)
  • 擅长烧、炖、熏
  • 徽州山珍
  • 腌腊、古井

代表技法:烧、炖、熏、烤

代表菜:

菜备注
徽州毛豆腐发酵长毛后煎
臭鳜鱼闻臭吃香
徽州一品锅山珍多层
黄山炖鸽山珍代表
红烧划水(徽版)鱼尾经典

李鸿章杂烩合肥名菜

黄山臭鳜鱼徽菜之魂

特色食材/调料:

  • 徽州火腿(与金华齐名)
  • 黄山毛峰(茶)
  • 巢湖鱼虾
  • 毛豆腐(发酵)
  • 臭鳜鱼(腌制发酵)

家常示范:臭鳜鱼

五、除了八大菜系,还有这些重要菜系

京菜(北京)

十一、几个误区

误区真相
"川菜 = 麻辣"川菜有 23 种味型,麻辣只是一部分
"粤菜 = 高级"家常粤菜(粤式快餐)同样平易近人
"鲁菜 = 大块炖"鲁菜刀工、火候极精细(九转大肠)
"淮扬菜 = 平淡"开水白菜的虚实相生,是顶级功夫
"湘菜 = 辣"湘江菜鲜辣,洞庭湖鱼鲜,差异大

十二、一句话总结

中国八大菜系是"水土 + 历史 + 文化"的结晶。
每个菜系背后都有地理和哲学:
- 鲁菜基朴 · 川菜新派 · 粤菜生猛
- 闽菜海咸 · 苏菜清雅 · 浙菜鲜爽
- 湘菜热烈 · 徽菜深沉
